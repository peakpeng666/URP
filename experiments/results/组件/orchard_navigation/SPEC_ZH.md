# 果园导航接口与验收规范

## 来源与范围

原文件为《立项申报书_20260315.docx》，[已核验的原文件](https://drive.google.com/file/d/1KANzgrMyEAbrnaPDNyE-C2hlzPIsqid3/view)。文件摘要在 `data/protocol.json.source_application.sha256`。第四节要求四类经典算法、农业仿真、统一指标及推荐交叉验证；第五节说明依托 Python、不涉及复杂硬件。本实验仅完成其中合成果园静态图搜索开发接口，未修改原申请书。

渲染原件的第 8 张图像（印刷页码 7）核对了长度、累计转角和时间公式；第 9 张图像（印刷页码 8）核对了果园行间导航等场景原文。申请书没有给出具体地图、栅格尺寸、足迹或随机种子，本实验均显式自定。

## 输入

`plan(map, query, algorithm)` 接受 Python 对象，不接收任意程序。

地图必需字段：`width`、`height` 是正整数；`resolution_m` 为正有限数；`robot_halfwidth_m`、`clearance_m` 为非负有限数；`obstacles` 为闭合障碍矩形数组。每个矩形 `[x0,y0,x1,y1]` 使用整数格下标，含两端，必须在图内。元数据包括 map_id、开发集标志、合成来源、行数与布局。

`start`、`goal` 均为 `[x,y]` 整数格坐标；布尔值不作整数接受。坐标须在图内且足迹可容纳。`algorithm` 仅接受 astar/dijkstra。已显式检查的数值、坐标、矩形越界和算法名错误抛出 ValueError。当前接口要求上述必需字段与容器形状存在；缺字段或破损容器还可能抛出 KeyError、TypeError、AttributeError，并未认证统一异常类型。无路可走是合法输入下的独立输出状态，不与输入错误混同。主实验全部输入已独立核对；若接入任意外部请求，应在独立后续版本增加完整schema检查和错误标准化。

坐标原点位于地块左下角，x 向右、y 向上。格中心的物理坐标为 `((x+0.5)*s,(y+0.5)*s)`；障碍矩形表示物理闭区域 `[x0*s,(x1+1)*s] × [y0*s,(y1+1)*s]`。外界禁行；正方形足迹半宽与余量之和为 rho。

求解器用整数格膨胀 `floor(rho/s+0.5)`，并单独检查外边界。当前求解器在无量纲膨胀计算中加1e-12，而独立验收的1e-12容差单位为米；任意参数下极接近接触边界时可能出现不一致。在本次 rho=0.35m、s=0.5m 时，障碍向每侧膨胀 1 格。规划状态仍是单个格中心，不包含车辆朝向。此方形仅为静态占用近似，不能解释为真实车辆转向模型。

有效边仅连接四个正交相邻的自由中心，成本 1 步。地图和算法不同尺度之间不共用或变更步成本；长度统一转为米。模型禁止斜向边。

## 输出

输出对象字段：

- `status`：ok 或 unreachable
- `path`：按顺序的整数 `[x,y]` 列表，包含起终点；不可达时为空列表
- `cost_steps`：成功路径边数；不可达时 null
- `cost_m`：成功路径米制长度；不可达时 null
- `search`：popped、expanded、stale_pops、neighbor_checks、relaxations、heap_pushes、max_frontier

`expanded` 指非过期堆项对应的已定距节点，包含成功弹出的目标；起终点相同时为 1。`popped` 包括过期条目；`neighbor_checks` 统计生成的可通行邻居，不统计边界或障碍方向；`relaxations` 只统计距离严格改善；`heap_pushes` 含初始起点。原始输出保留全部计数。

堆键 `(g+h,h,insertion_order,node,g)`；相邻方向顺序为东、北、西、南。启发 h 为 Manhattan 步数或 0；其一致性来自每次正交移动至多改变 Manhattan 值 1，障碍只删边不缩短图距离。故 A* 和 Dijkstra 应给出同一最优图成本，最短路线不必相同。h 平局规则会影响路线形状；不能把形状差异解释为额外优化目标。

## 独立验收

`validator.py` 不导入 model/planners。它逐点直接计算原矩形与足迹的几何关系，逐段检查方形足迹扫掠的轴对齐矩形和原障碍/地界是否相交；接触也视为碰撞。另一种建图与 FIFO BFS 实现独立重算可达性及最优步数。

成功输出同时满足：正确起点/终点，坐标类型与边界正确，全部点/段无碰撞，每步正交相邻，米制长度由原始路径重算且与上报相符，步数与独立 BFS 最优值相同。不可达输出须为空路径、空成本且独立 BFS 也判无路。累计转角按相邻方向的最小绝对角差计算；初始与末端没有指定朝向，不添加端点转角成本。

微型回归包括 3×3 空图最优 4 步、有缺口壁障最优 6 步、完全壁障不可达、1×1 同点最优 0 步和 5×1 直通最优 4 步。另有20张4×4图全部自由端点对。故障注入包含错误起终点、跳跃/出界/碰撞、错误成本、NaN/布尔伪数字、伪不可达、空成功路径、非法状态/路径类型和可行但非最优绕行。两条不同等长路径都应通过。

## 计时和比较

先运行 2 个非计分热身；顺序执行五轮完整查询。算法先后顺序由 `(query_index+repeat)%2` 交替，无并发。CPU 与墙钟从接收原始 map/query 后到返回完整路径计时，包含输入校验、建图和重建；评测器与写盘排除。未隐藏重试、运行失败或删去慢值。960 次调用分别保留。

先在每查询每算法内取五次中位数；先后顺序和原始纳秒值可检查。总体 CPU 比值先在每图8查询内取几何均值，再在12图间取几何均值；因每图查询数相同，也等于96查询比值的几何均值。非零可达和不可达子集另外报告，样本数与选择规则固定。搜索扩展比值使用算术均值，不与 CPU 几何平均混写。

所有五次输出和192次预定重放均按确定性字段核对。正式留出评估没有启动。本次地图来自同一构造器，因此仅为受控开发对照；没有随机田间采样、实际机器人执行或跨环境兼容证明。

主数据的9组等长不同路线均来自q06；独立检查确认A*累计3个直角转向、Dijkstra累计2个。这是既定平局规则选择的不同最短路线，不能解释为转角最优保证或运动学可执行性。历史verification中的independent_base_maps字段仅作底图数量读取，不作为统计独立性假设。

后验接口边界探针保留于qa/interface_boundary_checks.json，可用qa/check_interface_boundaries.py复现。例：s=0.5、halfwidth=0.24999999999925、clearance=0，7×7图中单障碍[3,3,3,3]，规划器接受[2,3]到[2,2]但验收器按其米制容差判碰撞。此时真实间隔小于皮米；这是数值容差约定不一致，不能推广声称任意参数都已认证。本次固定rho=0.35远离阈值，全部冻结路径仍通过独立核验。统一米制容差须放入新实现版本，不改本次冻结源码或回填结果。
