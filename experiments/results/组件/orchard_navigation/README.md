# 果园行间导航图搜索开发实验

本实验对齐《面向农业机器人的路径规划算法库构建与智能推荐方法研究》申报书第四节的“果园行间导航”、统一算法接口和评价指标，以及第五节的 Python 仿真条件。它建立农业场景的图搜索接口与可信开发基线。

**结论：A* 与 Dijkstra 在 84 个可达查询上得到相同最优图成本，另外 12 个查询均正确判定为不可达。** 当前合成图中，A* 在非零可达任务上通常减少搜索量，但不可达任务没有这种收益。此结果不能替代田间试验、运动约束验证、四类算法库或大模型推荐原型，也不是 CVRP-H1 证据。

## 实际完成

- 12 张合成底图：3 个规模 × 4 种静态布局
- 每图 8 个配对起终点，共 96 个查询：72 个非零可达、12 个起终点相同、12 个不可达
- 2 种确定性算法，各查询各计时 5 次，共 960 次主调用；另有 2 次热身、192 次确定性重放
- 主调用中 840 次产生合法最优路径，120 次正确返回不可达；0 次异常、0 次验收失败
- 192 次重放全部与原输出一致，包含路径、成本和搜索计数；计时数字不要求逐位相同
- 9 个可达查询出现等长不同路线，正常接受，不算错误；均为 q06，A* 为3次转向、Dijkstra为2次，是平局路径选择差异，不能据此声称任一算法具有转向约束或转角最优性

12张底图是12个开发比较分组；96 个查询并非 96 张独立底图，960 次调用也不是 960 个独立任务。三个尺度共享构造规则，同一底图内的查询与计时重复具有相关性；不做显著性或总体排名推断。

## 当前观测

以每个“查询 × 算法”的 5 次 CPU 时间中位数比较：

- 72 个非零可达查询，A*/Dijkstra CPU 比值的几何均值为 **0.4933**；扩展节点比值的算术均值为 **0.1166**
- 12 个不可达查询，两者扩展节点数相同；CPU 比值几何均值为 **1.2131**，A* 在此子集更慢
- 全部 96 查询按底图等权汇总，CPU 比值几何均值为 0.6016

时间包含输入检查、障碍膨胀建图、搜索和完整路径重建，不含独立验收与写盘；记录 CPU 与墙钟原值。本次没有分别计时预处理与纯搜索，因此上述比值只能称为端到端规划调用 CPU 比值。完整主循环（额外包含验收和写盘）用时约 5.30 秒，不能把此数作为单次算法时间。共享云环境、短时测量和当前实现会影响速度比；没有外部付费模型调用，云计算费用未获账单。

累计转角仅是申报书所述平滑度指标的离散代理：记录相邻段最小角差绝对值之和，处理 ±π 表示跨界。两算法都只优化路径长度，不优化转角；较小累计转角不能证明车辆能平顺行驶。

## 人工设定的仿真条件

- 0.5 米栅格，4 邻接，不能斜走；每条边成本 1 步，即 0.5 米
- 小/中/大图分别为 50×64、82×112、130×176 格，6/10/16 条作物行；均为 2 格行宽、6 格行间通道、8 格名义地头深度
- 布局：规则通行、局部行间封堵、地头障碍、横向完全隔断；完整障碍矩形和起终点冻结在 data/
- 静态足迹为边长 0.5 米、始终轴对齐的正方形，额外安全余量 0.1 米；外界及与障碍接触均不可通行
- 地图尺寸、足迹、安全余量和起终点是本实验自行规定，**不是申报书给定参数，也不是实地测量**
- A* 使用可采纳且一致的 Manhattan 启发；Dijkstra 使用零启发；统一边成本和确定性平局规则

不模拟朝向状态、转弯半径、速度、动力学、动态障碍、地面条件或传感误差；无连续空间最优性主张。正式保留测试集未生成、读取或评估，既有研究未改动。

## 检查与复现

运行环境 Python 3.12.14，仅用标准库；不需要安装新依赖。

```bash
cd URP/experiments/orchard_navigation

python src/run.py --out-dir results/reproduction_001
python src/analyze.py --out-dir results/reproduction_001

```

冻结入口为 data/freeze.json（SHA256：9b3a05d05f636c36d2a3bd217a18ea7fb0397efded0e021295c21556ce458bfb）。运行前后核对地图、查询、协议、实现与测试源码哈希；已有冻结不能被生成器覆盖。修改任务或算法时应另建版本，保留本次证据。

8 组测试覆盖已知最优值、不可达、起终点相同、等长替代路径、足迹碰撞与边界、非法输入、故意伪造输出，以及 20 张 4×4 随机微图所有自由起终点组合。独立验收器不导入求解器或其建图函数：它从原始障碍矩形重建几何，检查节点及线段扫掠碰撞，另用 BFS 重算单位边图最优值。微图使用固定测试种子；正式地图和求解器无随机种子。

## 文件入口

- `SPEC_ZH.md`：地图、接口、验收与计数口径
- `data/maps.json`、`queries.json`、`protocol.json`、`freeze.json`：运行前冻结
- `results/main/raw.jsonl`：960 次完整输出、路径、搜索计数、CPU/墙钟及验收结果
- `results/main/raw.csv`：便于筛选的运行级指标
- `results/main/replay.jsonl`：192 次重放证据
- `results/main/map_summary.json`：底图级汇总；`results/reporting_v2/paired_queries.json`、`summary.json`：准确区分可达成本与不可达判定的查询级和总摘要
- `results/main/verification.json`：独立重算结果
- `results/reporting_v2/viewer_data.json`、`VIEWER_INTEGRATION.md`：离线查看器扩展用的独立数据接口

本目录未修改现有查看器。数据接口需由查看器显式接入，不能塞入 CVRP 结果字段。`qa/application_render/` 仅为原申请书阅读检查产生的中间文件，不属于本实验交付数据。

报告口径说明：原始 `results/main/` 分析保留。其 `all_paired_costs_agree` 和不可达行的 `same_optimal_cost` 曾机械比较 null/null；不可达没有最优路径成本。`src/reporting_v2.py` 单独修正为84可达成本一致、12不可达判定正确，保留全部数值与原始数据，另存哈希及投影核验。

历史核验文件中的 `independent_base_maps: 12` 仅是底图分组计数，不表示统计独立；这些确定性的尺度/布局变体、图内查询和重复调用应作为嵌套观察解释。

接口边界：本次认证限于冻结参数和记录的测试。缺字段/破损容器的异常类型尚未统一；极接近接触边界的其他足迹参数存在求解器与验收器的容差单位不一致。后验探针及完整说明见SPEC_ZH.md与qa/interface_boundary_checks.json，固定主实验结果不受已发现问题影响；接入任意外部参数前应另版本修正并重新验证。
