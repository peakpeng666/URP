# P3：受限数学 DAG 两代教学对照

## 结果

这次固定研究完整结束并通过独立保存证据核验。22 次实际本地模型请求中，20 次在 384 个输出 token 上限停止，原文均未形成完整 JSON；另外 2 次以 EOS 正常结束，但在第三个节点把两个标量交给 `gt`，被固定类型规则拒绝。有效生成图为 0，没有任何模型生成候选进入装箱评分。

两臂都保留事前固定的手写 BF 种子。第二代没有使用第一代生成父代，因而本轮不能评价演化反馈比独立生成更好、更差或等效。首先暴露的是输出长度预算与受限语言类型合同的适配问题。

## 分母、数据与已执行评分

- 22 个真实请求 = 2 个共同初始化 + 演化臂 10 个 + 独立生成对照 10 个。每臂含共享初始化的机会数为 12，两臂数值不能直接相加成 24 次实际调用
- 保留 208 行完整计划账本：176 行候选评分未运行，32 行种子、承诺赢家及已发表公式参照评分有效完成，共 4,096 次物品放置
- 设计与验证各 4 个案例，分别由 2 条公开历史序列的前 128 个物品与容量 100/500 交叉组成，共 4 条底层序列。验证仅隔离于本次选择流程，不能称此前不可见或私有测试集
- 两个赢家均在验证前持久承诺为 BF。设计集 BF 使用 139 箱、L1 总和 132，超额比为 7/132；FF 为 140 箱。验证集两者均 134 箱、L1 总和 126，超额比为 4/63。这是种子表现，不能算 LLM 改进
- 已发表公式图仅作承诺后的参照：设计 144 箱，验证 140 箱。短前缀结果与之前 1k/5k/10k 完整实例不是同一评测，不能互相替代

## 成本与边界

实际外层起止为 2026-10-04 20:25:15.706489 至 20:45:50.196576 UTC，外层墙钟 1,234.490093 秒。正式进程内测得 2,443.875398 CPU 秒、1,234.400283 活动墙钟秒；其中 22 个模型服务器共 2,420.958896 CPU 秒。物理 token 总数为 10,024 输入、8,416 输出（含 2 个 EOS）。逐臂和共享初始化成本分别列在 `summary.json`，避免重复计账。

正式预算在完整调用预留后执行，没有缩限、补抽或修补。总预算 5,900 CPU 秒 / 3,660 活动墙钟秒已包含事前 200/200 准备扣账；最终扣账为 2,643.875398 / 1,434.400283 秒，未超限。可定位的准备实测 CPU 合计 135.618463 秒，包含失败接口尝试和最终冻结；历史人工编辑、部分外层核验及审计成本未测，200/200 是保守记账准备金，不是这些未知成本的数学上界。共享后端烟测在跨项目总账中只能算一次。逐子进程 CPU 和 `RUSAGE_CHILDREN` 的差为 0.000073 秒，原样披露。

模型为固定官方 Qwen3-4B Q4_K_M、固定 llama.cpp CPU 运行器。仓库名与嵌入模型标签存在已记录差异。它与原论文模型、完整 Python 候选空间、5,000 物品设计集和 20 代搜索均不同。本次只有一组种子化小型机制对照，没有统计显著性、算法创新或完整 EoH 复现结论。
