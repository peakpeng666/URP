# 复算说明

本交付保留历史输入字节、纯数值提取程序、手写 FF/BF、独立 checker、运行器、测试、冻结计划和全部已运行证据。无需安装 NumPy；正式基线实现只用 Python 标准库。原始历史许可证与当前来源许可证分别保存。

1. 优先核对 manifest 中每个文件的 SHA256。全部历史测试实例在 data/historical_numeric.json；当前 data/instances.json 是早期当前版数据比较产物，不是正式批次输入。prepared_plan.json 明确绑定历史实例哈希
2. 在新的复制目录重跑手写契约测试。保存现有结果目录，不覆盖历史证据。历史 pickle 仅由封闭语法的数据提取器读取，不使用 pickle.load，不导入作者源码
3. 当前 preparation_freeze.json 绑定本次 Python 3.12.14、解释器和标准库文件哈希。不同机器或运行时应建立新的准确冻结并复核；不能仅改路径后宣称原冻结仍有效
4. 正式入口只接受两个固定方法名，不能运行源码或插件。外部运行授权必须匹配新冻结、scope、60 请求上限和唯一 run_id；由运行者明确批准后执行一次。历史本地授权和单次使用记录不包含在公开包中
5. 对照完整分配、每格箱数/L1 和来源身份；时间、PID、RSS 随环境变化。若来源、预算、worker、输出或独立检查失败，保留所有已开始和未运行槽位并停止，不自动重试或放宽限制

本交付未包含依赖环境、下载缓存、私有批准材料或复核工作笔记。历史数据加正确容量语义的基线重评分不等于作者整个搜索流程复现。
