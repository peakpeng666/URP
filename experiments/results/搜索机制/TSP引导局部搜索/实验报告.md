# TSP 固定 GLS 与等 delta 预算多起点 2-opt：独立开发集组件实验

日期：2026-10-06 UTC。实验代码与数据在 03:31:41.691 UTC 冻结；正式运行于 03:31:41.803–03:31:50.533 UTC 完成。

## 结论先行

- **108/108 槽完成，108 条输出均通过独立 Hamilton 单闭环检查；无失败、无硬墙钟截断。**
- 主比较是固定 GLS 对等预算多起点 2-opt。n=50 的 6 个实例、每实例 3 种子中，GLS **13 胜、5 平、0 负**，配对原始欧氏长度平均降低 **1.1714%**；uniform 为 **1.5147%**，three-cluster 为 **0.8282%**。
- 六个 n=12 实例的计算距离模型最优值由穷尽 Held–Karp 子集 DP 求得，并由不同状态枚举实现复核。两主臂均 **18/18 达到参考最优，平均 gap=0**；单次参考只有 **12/18**，平均 gap **0.4341%**。
- 这仅支持“本批实例和预算下，经典固定罚项有助于这个 2-opt 宿主脱离部分局优”的组件结论。**不是 EoH/LLM 生成算法的端到端复现，不是 TSPLIB 复现，不证明通用优势。**

## 1. 证据与实现边界

研究背景来自 [EoH 主论文 P177](https://arxiv.org/abs/2401.02051)，本地原文提取文本 PDF18 页的 C.1 节，以及经典 [GLS 原论文 P231](https://doi.org/10.1016/S0377-2217(98)00099-X) 的已读本地笔记。P231 的 utility/增强目标见原 PDF3–5 页、无向 TSP edge feature 见10–14页、λ随首个局优归一化见15–16页。P231 原 PDF 本轮未重新取得；证据类型明确保留为既有阅读笔记。

EoH 用生成策略修改搜索景观，并包含 relocate 等其他宿主组件；其发表策略、完整进化循环、LLM、作者完整运行管线都未执行。本轮只实现经典 GLS 的固定 2-opt 组件对照，也没有使用 FLS、候选近邻表、3-opt 或 LK。

只借鉴/独立改写可信 CVRP 本地代码中的对称 2-opt delta、片段反转、成本重算，以及预算前置检查思想。参考文件作字节副本归档并 SHA256；**不导入其 solve，不导入 CVRP checker，不读取既有 holdout 或原132试验结果**。TSP 检查合同从零独立实现。

1/6 是本组件事前固定参数；虽 P231 笔记记录了原文特定实验采用该数值，也不能因此称它是作者普适最佳参数。

## 2. 冻结设计

| 项目 | 预先固定内容 |
|---|---|
| 数据 | 2族 × n12/n50 × 每格3实例，共12个全新可复现合成开发实例 |
| Uniform | 每点两个独立 U[0,1) 坐标 |
| Three-cluster | 中心(.2,.2)、(.8,.2)、(.5,.8)，轮流均衡分配；各坐标独立 Gaussian σ=.07，截断到[.001,.999]，最后打乱节点顺序 |
| 配对 | 每实例3个预冻结新搜索种子；同种子的三臂共享相同首始排列，节点0固定 |
| 总槽 | 12 × 3 × 3 =108，无重抽种子、无结果筛选 |
| 主臂预算 | 每run最多100000次真实2-opt delta、3秒求解CPU、8秒外部进程硬墙钟 |
| 顺序 | 实例与种子按冻结顺序，三臂执行顺序按pair index循环旋转 |
| 改善阈值 | 1e-12；2-opt 按(i,j)字典序完整 best-improvement，严格最小值并列保留首个 |
| 罚项 | λ=首个局优原始长度/(6n)，之后固定；utility=d/(1+p) |
| Utility平局 | 当前边中距最大utility不超过1e-12的全部边各加1，按无向端点排序 |
| 不完整扫描 | 不采纳未扫完邻域的候选；返回此前已完整接受、按原始d记录的best |

单次 2-opt 为弱参考，到首个局优结束。多起点臂到局优后随机重启，随机发生器继续相同首始种子的序列。GLS 到首个原始局优后用 d+λp 搜索，局优时加罚，并始终按原始 d 保存与评分最好路径。

DP 只用于独立参考和事后 gap；求解 worker 不读取 DP 文件，不把达到最优用作提前停止信号。坐标和所有种子在 `data/instances.json`；冻结参数在 `data/config.json`。

## 3. 结果

改善率定义为 100×(多起点原始长度−GLS原始长度)/多起点原始长度。先在每实例内平均3个种子，再在同族实例间平均；本轮平衡设计下等于配对种子的简单平均。

| 族/规模 | 实例数 | 种子对数 | GLS胜/平/负 | 平均改善率 |
|---|---:|---:|---:|---:|
| uniform n12 | 3 | 9 | 0/9/0 | 0.0000% |
| three-cluster n12 | 3 | 9 | 0/9/0 | 0.0000% |
| uniform n50 | 3 | 9 | 5/4/0 | 1.5147% |
| three-cluster n50 | 3 | 9 | 8/1/0 | 0.8282% |

n50 六个实例的种子均值改善依次为：uniform **1.0698%、2.3353%、1.1389%**；three-cluster **1.2721%、0.5791%、0.6334%**。18个种子对最大改善为5.9298%，不能用这个最好值替代平均效果。

**不报告 n50 最优 gap**，因为没有独立最优证据。n12 的 gap 则只相对于本轮不取整的 binary64 欧氏距离计算模型。DP 穷尽所有子集/终点状态，但浮点加法并非实数精确算术；判定容差为绝对1e-9。

科研图：`figures/tsp_gls_results.svg` 和 `figures/tsp_gls_results.png`。CSV 包含逐run、逐配对、逐实例、分层和资源统计，可从原始账本重建。

## 4. 实际工作量与预算账

| n/臂 | 平均真实delta | 平均CPU毫秒 | 平均重启 | 平均罚更新 |
|---|---:|---:|---:|---:|
| 12 单次 | 450 | 0.020* | 0 | 0 |
| 12 多起点 | 100000 | 56.574 | 216.67 | 0 |
| 12 GLS | 100000 | 61.860 | 0 | 676.50 |
| 50 单次 | 54572.22 | 27.042 | 0 | 0 |
| 50 多起点 | 100000 | 51.079 | 1.17 | 0 |
| 50 GLS | 100000 | 52.457 | 0 | 22.78 |

72个主比较run都以delta上限终止；36个单次参考都到首个局优提前结束。n50的多起点预算仅支持约1–2次额外重启，这是此预算下的机制差异，不能把结果外推到更多重启或更大预算。

*短小单次run中有17个CPU原始读数为0；计时系统宣告纳秒分辨率，但这些极短观测显然不足以精确衡量成本，原值照录、不平滑、不据此作速度结论。n12单次平均墙钟为0.361毫秒。

- 求解CPU总和4.4826秒；求解墙钟总和4.6772秒
- 各worker进程端到端墙钟总和8.5903秒，包含解释器启动、读取输入、结果序列化等额外开销
- 正式调度墙钟8.7303秒，不包含其前单独DP预处理
- 六个DP预处理CPU0.07621秒、墙钟0.07621秒；每实例11264个状态、56320个状态转移
- 首次独立完整审计CPU0.33818秒、墙钟0.33830秒；末次审计时间另见audit.json，具体检查成本逐run另记
- 所有求解run均含自己的距离矩阵/邻域构建成本，并单独记录求解内预处理时间
- GLS总CPU约为多起点的1.0619倍；**相同delta上限不等于完全相同CPU**。没有据此声明GLS更快

delta前置guard同时检查work、CPU、墙钟；额外CPU signal限制，外部调度进程逐个启动唯一计算worker，并在8秒墙钟杀死超时worker。进程创建和kill传递存在操作系统调度粒度；实际无run接近3/8秒。罚更新、重启、全路径成本重算、距离与utility工作均另计，不能将一次罚更新当作一次delta。罚日志的构建计入求解；最终输出序列化在求解CPU计时之外，但纳入进程墙钟。

## 5. 正确性与复核

冻结前六组小测试、正式后再次运行均通过：

1. n3–8 全排列最优对照 Held–Karp 与另一实现DP
2. n3–12 小例全部合法2-opt move，原始与增强目标delta对整条路径重算
3. 拒绝重复点、缺点、非法节点、bool节点、多路线及错误原始长度
4. work=0/1/7/19 的真实delta函数调用数与预算账一致，预算在计算前检查
5. CPU/墙钟guard在预算耗尽时不承认额外delta
6. 对称utility平局与增强目标搜索、原始目标best保存

独立 `audit.py` 不导入求解器或CVRP检查器，从原坐标用平方根重新计算108条最终单闭环；最大长度偏差8.88e-16。36组首始路径配对一致。六个n12 DP由不同稠密mask实现再次求解，全部差0。**12587次罚更新**逐条检查当前路线、utility最大边选择、罚计数和增强长度。冻结文件全部哈希不变。

追加安全路径测试在正式实验之后进行，独立记录，未改变正式参数或重跑正式槽：验证短CPU/短墙钟退出、CPU信号退出、外部supervisor超时kill。它们是安全探针，不属于108个结果槽。
