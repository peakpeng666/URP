# CVRP算法库

当前入口是 scripts/baseline.py；算法ID以 protocol/formal_plan.json 的17项清单为准。旧五项准入记录保留作历史，不代表当前算法库范围。

## 快速使用

在工程根目录、已安装依赖的Python环境中：

    .venv/bin/python scripts/baseline.py algorithms
    .venv/bin/python scripts/baseline.py cases
    .venv/bin/python scripts/baseline.py run --case A-n32-k5 --algorithm pyvrp --seed 0 --budget 5 --name my-first-run

单例调用在 user-runs/my-first-run 新建记录，输出原始路线、状态、耗时以及独立验算。不会覆盖正式实验。最近邻或其他启发式找不到满足车辆上限的解时如实报告，不把“未找到”称作数学上不可行。当前公共入口支持已登记的53个标准问题和1/5秒预算；接入新问题时先补齐距离、车辆与参考合同。

Python中直接调用：

    from scripts.baseline import algorithms, cases, solve
    print(algorithms())
    outcome = solve("A-n32-k5", "pyvrp", seed=0, budget=5, run_name="python-example")

solve会实际求解并独立评分，返回result/evaluation文件位置；导入与列举不会启动实验。算法实现位于 src/research/src/urp_research/cvrplib/，统一payload与截止时间由现有运行器处理；面板或其他程序应调用这一入口，不复制一套算法。

## 复现与验算

    .venv/bin/python scripts/baseline.py reproduce --name reproduction-01

默认仅显示完整4505项串行复现命令。确需新一轮完整执行时加 --execute；会写入独立user-runs目录，不追加为原论文实验。完整复现可能耗时数小时。硬件不同，时间不能直接与原批次混排。

    .venv/bin/python scripts/baseline.py verify --result user-runs/my-first-run/result.json --name recheck-01
    .venv/bin/python scripts/baseline.py summarize --runs <正式结果根目录> --out <汇总目录>

summarize使用冻结主计划和当前v3分工，保留未启动/失败分母并按主机、资源批次统计。新单例调用不混入正式矩阵。

## 本轮分工与结果

4505项主计划不变：云端seed0/2，共1802项；本机seed1/3/4，共2703项。云端seed0串行，seed2在0/1/2/3核四路并行；本机4个P核各一个单线程进程，先3/4再1。不同资源批次分别统计；云端每资源批次一次运行，本机同资源配置时最多3次。原始日志与实际resource_cohort记录是统计依据。

协议见 protocol/基线实验协议.md 与 execution_allocation_amendment.md；来源见 algorithm_inventory.md；报告/图表命令见 reports/README.md。GA/PSO/DE的随机键+Split是本轮教学适配，不冒称旧CVRP复现。
