# 预注册协议：农业结构特征驱动的实例级算法选择（E1–E4）

状态：**草案 v0.9，待冻结**。冻结条件：导师确认特征清单与测试集来源后，将本文件状态改为 FROZEN 并记录提交 SHA。冻结后任何修改只能以"偏差登记"附录形式追加。

日期：2026-10-21。关联计划：`paper/PAPER_PLAN.md` 主线 A。本协议落实 `docs/下一阶段.md` §3、§5 的判据与隔离纪律。

## 1. 假设（先验登记，实验前不可改）

- **H1（主假设）**：在按来源隔离的未见测试集上，使用农业结构特征的实例级选择器，相对固定强基线 PyVRP 的**逐实例相对成本均值 < 0**，且 95% 置信区间不含 0。
- **H2（可行率）**：选择器可行率不低于强基线的可行率减 1 个百分点。
- **H3（机制）**：收益（若有）在"高转弯代价占比 + 大长宽比田块"子群上显著高于其余子群（交互效应方向已登记，避免事后挑选子群）。
- **H0（已知事实，非假设）**：纯欧氏/规模特征在本项目 120 例实验中不产生选择收益（测试集 30 例替代选择 0 次）——本协议的特征集必须与该实验所用特征显式区分。

## 2. 变量

- **处理变量**：特征集 ∈ {基线几何特征（对照臂），基线 + 农业结构特征（处理臂）}；选择器 ∈ {1NN，代价敏感 logistic}（两个均预先登记，不事后换模型）。
- **结果变量**：主要 = 逐实例相对成本的实例等权均值（相对固定 PyVRP）；次要 = 可行率、胜/平/负、含全部开销的净墙钟成本。
- **VBS** 仅作诊断上界，不作主结论。

## 3. 数据划分与来源隔离

1. **CVRP/TSP 类**：历史已使用的 53 问题（51 底本）登记为"已污染"，仅用于开发与校准；**测试集 = 未使用过的 CVRPLIB 新底本**，同底本的序列/旋转/尺度变体归入同组。
2. **农业类**：按原始田块分组；NL124 田块若已用于特征工程调试，则整块划入开发侧，测试侧使用新来源田块几何。
3. 划分清单（实例 ID → 开发/校准/测试）在冻结时作为附录 A 落盘，SHA 记入本文件。
4. 样本量目标：测试集 ≥ 48 题（对齐时间窗新几何实验规模，便于借用其功效分析）；若不足，登记实际规模并报告功效。

## 4. 预算与全部成本核算

- 每算法求解预算：与系统默认一致 **3 秒、种子 42**（刻意不同于历史 0.25 秒评估合同，登记差异）。
- 计入成本：特征提取、选择器推理、求解、失败回退（回退策略 = 固定 PyVRP，预先登记）。
- LLM 不参与本协议（准入闭环 E5 另立协议）。

## 5. 统计检验（预先登记）

- 主比较：配对 Wilcoxon 符号秩检验（选择器 vs PyVRP 逐实例相对成本），单侧，α=0.05；同时报告 Hodges–Lehmann 效应量与 95% CI。
- 特征集消融（对照臂 vs 处理臂）为第二比较，Bonferroni 校正 α=0.025。
- 子群交互（H3）：预先按"转弯代价占比 × 长宽比"中位数切分四象限，只做这一次切分。
- 不做跨硬件耗时排名；耗时仅作描述性汇总（沿用仓库纪律）。

## 6. 停止与报告规则

- 测试集只在方法、特征、参数全部冻结后运行**一次**。若开发侧显示候选无互补性（对照臂与处理臂 VBS 无差异），停止并改写论文角度为边界条件研究（PAPER_PLAN 主线 A 风险条款）。
- 无论结果正负，报告：主结果表、可行率、胜/平/负、VBS 上界、误选分析、全部成本表、失败与无有效解清单。
- 原始记录包命名 `selector-agri-feat-v1-<date>.zip`，哈希登记回本文件附录 B。
