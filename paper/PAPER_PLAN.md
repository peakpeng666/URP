# URP 论文主计划

更新于 2026-10-21。本计划回答三个问题：**写什么、凭什么能发、还缺什么**。
依据为 `docs/导师查看.md`、`docs/下一阶段.md` 与冻结基准记录；所有历史数字以原报告为准，本文件只做组织与决策。

---

## 0. 一句话定位

> 面向农业机器人作业的转弯与田块约束路径规划：一个统一算法库、一套经独立验算的冻结基准，以及实例级算法选择方法的系统性研究。

核心卖点不是"又一个算法"，而是三件别人难同时拿出的东西：

1. **覆盖 5 类问题的统一算法库**（28 注册配置 + 17 配置正式 CVRP 比较），统一入口、统一独立验算；
2. **4505 项带证据链的冻结基准**（17 配置 × 53 问题 × 5 种子，4316 项独立验算可行），含农业真实田块几何；
3. **诚实的实例级选择研究**：双候选 CVRP 选择器零收益（负结果）、时间窗新几何上八特征消融的积极线索、BPP 前缀选择的收益与分布迁移风险并存——这是"算法选择何时有效、何时无效"的实证素材，比单纯报正结果更有发表价值。

## 1. 选题决策：三条候选主线

### 主线 A（推荐）：转弯感知与田块约束下的农业路径规划——算法库、基准与实例级选择

- **命题**：通用欧氏 CVRP 特征无法区分农业实例的算法优劣（本项目已证明：选择器在纯欧氏特征下零收益）；引入转弯成本、田块几何、容量分组等农业结构特征后，实例级选择能产生可测量的净收益。
- **已有资产**：转弯任务 5 配置（模式分层 DP、原图状态精确搜索、方向松弛 DP）、NL124 田块代理损失分析（13/124 块田存在代理损失、损失高度集中于地块 42）、时间窗新几何 80/48 划分实验、120 例选择器零收益基线。
- **关键缺口**：农业特征集的系统构建与消融；按田块分组隔离的新测试集；净收益的显著性检验。
- **目标期刊（按顺序）**：Computers and Electronics in Agriculture（Q1，农业 + 算法选择正中 scope）→ Biosystems Engineering → Precision Agriculture。
- **风险**：若新测试集上仍无净收益，论文转为"农业路由算法选择的边界条件"实证研究——负结果 + VBS 上界分析本身就是贡献，但期刊档次降一档。

### 主线 B（备选）：LLM 生成算法组件的准入控制——生成不难得，准入才是关键

- **命题**：LLM（EOH 式演化）能稳定产出可准入的路径算法组件（已有：60 逻辑槽 43 完整候选，EOH 24/30 vs IID 19/30），但"是否入库"需要显式准入规则；比较四种准入规则（单成员成绩 / VBS 增量 / 实际选择收益 / 策略残差）对最终策略净收益的影响。
- **已有资产**：P0/P1/P2 分阶段实验、GLM-5.3 三档 36 任务消融、`docs/下一阶段.md` §5 的四种准入规则 + 五种对照协议草案。
- **关键缺口**：协议尚未冻结执行；需要独立留出评价序列；需要与 FunSearch/EOH 类工作的显式对比。
- **目标**：若做扎实可投 GECCO / AAAI workshop / IEEE TEVC 短文；作为主线 A 的一节则更稳。
- **风险**：生成侧工程量大，且审稿人对 LLM 生成算法的可复现性要求越来越高——必须冻结模型快照与 token 预算。

### 主线 C（保底）：农业机器人路径规划的可复现基准与证据链

- **命题**：发布一套带独立验算、环境证据链和冻结协议的农业路由基准（CVRPLIB 主计划 + 农业田块实例 + 转弯任务），解决该领域"结果不可复核、配置不可比"的痛点。
- **已有资产**：4505 项冻结计划、归档重审机制、host manifest / FROZEN resource manifest 三级证据。
- **关键缺口**：3604 项记录的主机证明链待追回；基准需要公开打包（实例 + 验算器 + 参考解）。
- **目标**：期刊的数据/基准类栏目，或作为主线 A 的实验基础设施章节。

**决策建议：A 为主，B 的准入实验作为 A 的方法章节之一，C 作为 A 的实验设置与可复现性章节。一篇论文讲清一件事：农业结构特征让实例级算法选择在转弯/田块约束下产生净收益。**

## 2. 研究问题与预期贡献

### 研究问题

- **RQ1（特征）**：哪些农业结构特征（转弯代价、田块长宽比与凹凸性、地头几何、容量-行程结构）能区分实例上算法的相对优劣？纯欧氏特征已证无效，新特征集的增量价值是多少？
- **RQ2（方法）**：在按田块/底本来源隔离的划分下，基于农业特征的实例级选择相对固定强基线（PyVRP / SAV）是否取得统计显著的净收益？计入特征、选择、求解、回退的全部成本后是否仍为正？
- **RQ3（边界）**：选择收益在何种实例子群上出现/消失？VBS 上界与实际策略的差距由误选还是候选互补性不足主导？

### 预期贡献声明（投稿信口径）

1. 一个覆盖点到点、CVRP、转弯、覆盖、车队五类问题的农业路径规划算法库与统一验算接口（28 配置，开源）；
2. 一套 4505 项、带独立验算与环境证据链的冻结基准及农业田块实例集；
3. 农业结构特征驱动的实例级算法选择方法，及"何时有效/何时无效"的实证边界（含负结果）；
4. LLM 生成算法组件的准入控制协议与初步证据（若主线 B 实验完成）。

## 4. 让项目"更智能"的升级方向（按对论文的边际贡献排序）

1. **从规则解析到受约束 LLM 场景理解**（当前自然语言入口是规则+词汇解析）：接结构化输出 + 校验器的 LLM 前端，把"田块描述 → 任务合同 → 候选算法 + 理由"做成可审计链路。这是题目中"智能推荐"的正名之战，必须有独立留出集上的准确率/拒绝率数字。
2. **执行反馈闭环**：用 Gazebo 执行结果（轨迹偏差、打滑、任务完成）回写实例特征库，让选择器从"规划时特征"进化到"执行后特征"。这是从 algorithm selection 走向 experience-based selection 的跃迁，也是 RQ3 的延伸实验。
3. **特征即贡献**：把农业结构特征集做成独立可复用构件（输入田块 GeoJSON → 特征向量），附带 NL124 式的代理损失诊断工具。工具型贡献引用率最高。
4. **多车从串行预约到冲突感知调度**：当前多车是串行执行基线，若加入田块级冲突预测（基于覆盖几何），makespan 对比就是一张新表。
