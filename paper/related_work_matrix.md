# 相关工作定位矩阵

更新于 2026-10-21。基于 `literature/` 565 篇精读笔记（16 个主题）整理，用于论文 related work 章节与投稿信的定位陈述。原则：**不堆砌引用，每一行回答"我们差在哪、赢在哪"**。

## 1. LLM 自动算法设计（主线 B 对话对象）

| 对标工作 | 它做了什么 | 我们的差异与增量 |
|---|---|---|
| EoH (LLM 演化启发式) | 演化式生成启发式组件 | 我们复现了其装箱线并多装 30 箱（新 20 序列）；增量是**准入控制**：生成后是否入库由四种显式规则裁决，EoH 无此概念 |
| FunSearch / ReEvo / AlphaEvolve | 程序空间搜索 + 评估闭环 | 它们以"最好候选的公开得分"为终点；我们把**生成—准入—选择—拒判**全链拆开评估，区分 VBS 上界与实际策略净收益 |
| DreamCoder / 库学习 | 从经验中长出可复用构件 | 我们的"库"是带预算、种子、验算合同的算法库，构件入库有审计链 |

**定位句**：已有工作回答"LLM 能否生成好算法"；我们回答"生成之后，算法库该如何决定收不收、收了之后选择器用不用、分布外该不该拒"。这一闭环在文献中尚无系统实证。

## 2. 算法选择与配置（主线 A 方法基座）

| 对标工作 | 它做了什么 | 我们的差异与增量 |
|---|---|---|
| AutoFolio / 经典 AS | 实例特征 → 逐实例选算法 | 我们提供**反例**：纯欧氏特征在 120 例上零收益（测试集替代选择 0 次），说明特征工程即研究对象；农业结构特征是新增量 |
| SH / Hyperband / BOHB | 预算分配与配置搜索 | 作为预算纪律引入；我们的预算含特征、选择、回退全成本核算，比仅计求解时间更严 |
| 校准与拒判（CRC 谱系） | 不确定时拒判 | 已有证据：CRC 门控在新分布拒掉全部 32 个非基线推荐——拒判正确性是分布迁移下的安全阀，论文中作为 H2 之外的鲁棒性结果 |

## 3. VRP 求解器与元启发式（实验对照）

| 对标 | 角色 |
|---|---|
| PyVRP / HGS (Vidal) | 固定强基线（主计划 265/265 可行、平均参考差距 0.341%）；模式优化文献为转弯 DP 提供理论对照 |
| AILS-II / SISR | vendor 对照 120 项已审计；论文中作为"同预算 SOTA 参照" |
| GA/PSO/DE random-key + Split | 自实现族，Split 经 1080 例枚举校验——实现正确性证据 |

**短板直认**：缺神经路由学习基线（AM/POMO 训练未复现）。两个处理方案：(a) 论文显式限定为"经典与 LLM 生成方法"，神经路由列为 future work；(b) 若时间允许补小规模 AM 训练作参照。推荐 (a)，避免拖期。

## 4. 农业覆盖与田块物流（应用领域对话）

| 对标工作 | 它做了什么 | 我们的差异与增量 |
|---|---|---|
| Fields2Cover / Soil2Cover | 田块覆盖路径全流程 | 我们集成并修复其完整路径（内缩作业区覆盖 100%），增量是覆盖与转弯/车队任务的**统一验算**与物理复验 |
| Field Logistics I/II | 田间物流优化 | 我们的 144 异构车具配对（联合 109 可行 vs 分阶段 92–95）与 72 例 Dubins 排序（欧氏排序多走 18.94%）提供了**约束不可省略的定量证据** |
| NL124 真实田块 | 几何来源 | 代理损失集中性分析（13/124 有损、地块 42 贡献 70.79%）是"几何近似何时安全"的实证 |

**可写成的硬贡献**：转弯方向、车具兼容、容量状态省略后的反例集（32 例出错、分阶段丢可行解、Dubins 边界不可行证书）——"农业 VRP 建模的形式化与反例"在农业工程期刊极受欢迎。

## 5. 投稿定位结论

- **首选 Computers and Electronics in Agriculture**：真实田块 + 转弯/车具约束基准 + 实例级选择，三样齐全即中 scope；负结果与拒判机制是差异化卖点。
- **第二篇（后置）**：LLM 生成—准入—选择—拒判闭环，冲 GECCO / AAAI / EJOR 方法学线。
- **必须在正文声明的边界**：无实机实验（仿真限同构差速车）、无神经路由基线、3604 项记录证据链等级、容器/原生执行差异。主动声明 = 审稿人无可乘之机。
