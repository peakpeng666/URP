## 目录与存储

- `src/`：项目源码与第三方代码。
- `data/`：输入数据与算例。
- `papers/`：论文原文。
- `literature/`：阅读笔记与教材。
- `materials/`：教师材料。
- `experiments/`：研究输出。
- `protocol/`：正式基线协议。
- `independent/`：独立验证器。

`acceptance/`、`audits/`、`evidence/`、`patches/` 和 `runtime/cvrplib/` 保存已有研究记录及复现要求，保留原路径和原始内容。`baseline-worker/` 是独立的本机实验工作区，不属于应用缓存。

## 运行数据

CVRP 数值任务及可写档案库位于 `.local-state/`，工程检查默认输出到 `user-runs/`。`data/backend/` 保留原始档案，新任务写入 `.local-state/`。历史审查和实验报告保留各自日期。

田间应用的运行数据、SQLite、会话、缓存和本地构建位于 `src/lab/runtime/`。各项目的依赖环境保留在各自的 `.venv/` 或 `node_modules/`。

`setup/YYYY-MM-DD/` 按日期存放部署与测试证据，业务模块放在对应源码目录。隐藏工具配置与 Git 历史由对应工具管理。

## 目录维护

`python3 tools/project_audit.py` 执行只读盘点。

加 `--clean-cache` 时，仅清理白名单内的后端 Python 缓存，保留数据库、日志、证据、环境和模型。

两种操作均可用 `--output 路径.json` 保存清单。
