## 农业案例与评价

申报方案列出果园行间导航、不规则地块覆盖、多点任务调度等典型场景。每个案例建立“需求→输入→算法→检查器→原始结果→图表”的链，算法使用相同约束和预算比较。

- 点到点/运动规划：可行率、长度、规划时间、平滑度及避障表现。
- 覆盖规划：漏覆盖、重覆盖、非作业路程、转弯与边界约束。
- 路由/调度：可行率、成本、工期、等待和任务约束。
- 动态任务：恢复成功率、重规划延迟、碰撞/冲突及累计代价。

真实田块几何、几何上生成的作业任务、物理仿真和实地采集分别标注；跨任务指标按任务族报告。具体案例数量由正式验收口径确认。

## 当前决策

1. 先完成工程、数据、证据与研究地图的统一整理，再据可证伪问题选择下一批工作。
2. 保留传统规划、学习增强、自动算法设计、科研 Agent 等并行候选；不把旧算法清单、特定训练路线或单一框架作为实现约束。
3. 每项研究先定义主指标、预算、独立样本单位、对照和最终测试隔离，再生成实验结论。
4. 工程贡献以可靠执行、恢复、可追溯和复核效率评价；算法贡献以同预算强基线、消融与泛化证据评价。
