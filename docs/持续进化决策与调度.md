# 持续进化的路径决策与任务调度：与现有工作台的融合方案

日期：2026-10-23。状态：**P1（第一阶段）开发侧完成**：经验库、特征、互补性审计、受门控的尝试顺序策略均已跑完并给出开发侧结论（见[审计报告](../experiments/reports/进化决策/农业组合互补性审计与覆盖尝试顺序.md)）；封存测试待预注册修订冻结后一次性运行。承接[下一阶段](下一阶段.md) §2「在强基线上研究改进与智能推荐」、`paper` 分支论文主计划的主线 A/B，以及[前沿调研报告](../literature/深度调研/URP前沿技术批判性深度调研报告.md) §3 的“先做互补性审计”。

## 1. 一句话

不另起一套系统。在现有「任务 → 推荐 → 求解 → 独立验算 → 仿真执行 → 记录」链路旁接一条「**经验 → 学习 → 门控上线**」回路：每次求解和执行都成为经验；学习只在测得有提升空间的位置上线；任何学习策略都能回退到规则或固定强基线，并在界面和导出中与规则推荐分开标注。

## 3. 关键判断：学习要放在有提升空间的地方

选择器能拿到的最大收益是逐实例最好（VBS）与固定单算法（SBS）之差；这个差为零时，再强的学习器也没有收益（调研报告 §3.1）。开发侧试探结果：

| 问题 | 数据（均为开发侧） | 观察（2026-10-23 审计最终数字） | 对“学什么”的含义 |
|---|---|---|---|
| CVRP，5 s | 冻结 4505 项归档，53 问题均属已污染开发数据 | 单一最好（PyVRP，265/265 可行）与逐实例最好之差 0.017%（95% 区间 [0.001%, 0.045%]） | 选“哪个求解器”几乎没有空间，与 120 例选择器零收益一致 |
| 真实田块多车，3 s | 荷兰 140 块、350 个实例（行间/自由通行 × 规模/分布/单多趟轮换，另 70 个最晚完成） | 总里程余量 1.10% [0.00%, 2.92%]（PyVRP 最好），最晚完成余量 0.17%（OR-Tools 最好）；35 条 error 为实例级、五算法一致 | 空间不在选求解器，而在预算/时效、执行反馈和动态调度 |
| 真实田块覆盖 | 荷兰 140 块 × 3 种机具，几何准入后 388 实例 × 11 配置 | 现行默认（牛耕·最少作业行）可行 254/388（65.5%，工作台默认机具仅 55.1%）；单一最好（不分解·最少作业行）326/388；任一配置 373/388；余量 13.1% [9.7%, 17.0%] | 有真实的配置选择/尝试顺序空间，主要体现为可行率 |

**第 2 轮复核（2026-10-23/24）修正了两点解读：**

- 多车的 1.10% 不是算法互补性。它来自通行图与检查器之间毫米级的几何容差不一致；用「先 PyVRP、失败再 OR-Tools」回退就能 274/274 可行（报告 §7.2）。
- 覆盖规划的「可行」需要分清三层：
  - 官方检查会放过长弦拐角；
  - 严格 2 cm 检查又会拒绝控制器可吸收的小折角；
  - 倒圆判定（以最小转弯半径倒圆、偏离 ≤1 cm、再用未修改的检查器复核）保留了 85.2% 的官方可行路径，对容差不敏感（报告 §7.1）。
- 选择余量和学习收益都要在三种判定下分别报告；建议封存协议以倒圆判定为主。

正式数字来自冻结计划 `experiments/runs/evolve-audit-20261023`（6018 项全部终态，失败、超时、实例错误计入分母）与[审计报告](../experiments/reports/进化决策/农业组合互补性审计与覆盖尝试顺序.md)；覆盖尝试顺序的结论（经验静态顺序晋升、学习策略未超静态）见报告 §3。

## 4. 架构：一个经验库、三条回路、一层安全门

```
             ┌──────────────────────── 安全门 ────────────────────────┐
任务/事件 ──► 特征提取 ──► 决策策略（冠军） ──► 求解/重规划 ──► 独立验算 ──► 仿真执行 ──► 记录
                 ▲            │ 门控不通过→规则/SBS                   │             │
                 │            ▼                                        ▼             ▼
                 └──────── 经验库（版本化、可追溯、按田块/底本分组） ◄──────────────┘
                              │            │              │
                    ①决策学习（每次）  ②算法库进化（批次）  ③执行反馈（仿真后）
```

- **经验库**：每条经验记录实例快照与特征版本、候选集合、实际执行的动作、所有观测结果（成本、独立验算、墙钟/CPU）、可选的执行结果、策略版本、来源（用户任务/研究批次/基准）和数据划分标签（开发/封存测试）。来源为上表的求解记录、离线组合扫描、仿真结果和 CVRP 归档。
- **回路①决策学习**：上下文为实例特征，动作为“算法/配置/预算”的有序尝试表（前一项未通过独立验算再试下一项），反馈来自独立验算。先用可审计的 1NN 和代价敏感 logistic，再考虑更复杂模型。评价用先测后学（prequential）：每来一个新实例，先用当前模型决策并记账，再把结果加入经验库。
- **回路②算法库进化**：按边际贡献决定准入与退役，四种准入依据（单成员成绩、VBS 增量、实际选择收益、当前策略残差）沿用下一阶段 §2 的协议。候选可来自参数化配置、LLM 生成的求解器组件（论文主线 B）或外部求解器；每次入库都重新绑定特征、模型、预算和校准版本。
- **回路③执行反馈**：用田间仿真的规划—实际配对学习残差模型（用时、偏差、失败风险），回写为调度目标（期望执行时间、风险当量），使选择从“规划时特征”走向“执行后经验”。
- **任务调度层**：现行为静态多车 VRP 加串行交通预约。演进方向是事件驱动的滚动重规划（对应“动态任务流”提案：新任务或延误到来时，由策略决定快速插入还是整体重解及其预算）、多机共道冲突调度（替代串行预约），以及使用回路③学得的用时。
- **安全门**：线上只运行“冠军”策略；“挑战者”须在冻结验证划分上满足预先登记的晋升判据才能替换冠军；逐实例用保形风险控制与分布外距离决定是否回退规则/SBS；每个模型有模型卡、训练数据哈希和适用范围，可一键回滚。

## 5. 融合到代码：改哪里、不改哪里

| 工作 | 位置 | 说明 |
|---|---|---|
| 新增经验与学习模块 | `src/lab/urp_lab/evolve/` | `features`（农业结构特征）、`experience`（经验库构建）、`sweep`（离线组合扫描）、`audit`（互补性审计）、`policy`（选择/尝试顺序策略与门控）、`prequential`（先测后学评价） |
| 推荐挂钩 | `src/lab/urp_lab/recommend.py` | 只做增量：存在已晋升模型且实例在适用范围内时使用学习策略并返回策略版本、门控与模型卡；否则保持现有 `rules-v2` / CVRP kNN 行为 |
| 只读接口与界面 | `gateway.py`、前端决策记录与科研面板 | 后续增量加入学习曲线、互补性地图和模型卡；不改现有入口 |
| 不改 | 求解器内部、ROS/Gazebo 会话与仿真后端 | 由负责方维护；本方案只经 `run_algorithm`、运行记录和仿真结果文件取数，发现的问题写成接口需求 |

已发现、需负责方处理的问题：makespan 目标下 OR-Tools 调度未在时限内得到解时，`ortools_makespan` 返回空结果，上层未转成“无解”状态而直接抛出异常（试探实例：nl_field_12，120 点、4 车、容量 15，3 s）。

## 6. 科研设计

| 研究问题 | 评价 | 纪律 |
|---|---|---|
| E1 互补性：组合中哪里存在 VBS−SBS 空间？ | 各问题类与实例切片的 VBS/SBS 差距、可行率差、Shapley 边际贡献 | 开发数据；失败与超时进入分母 |
| E2 持续选择：经验驱动的策略能否在不损失可行率的前提下降低遗憾？ | 先测后学的累计遗憾曲线、相对 SBS 的逐实例成本、可行率、门控回退率 | 按田块分组；冷启动与分布迁移分别报告 |
| E3 算法库进化：按边际贡献准入是否提升实际策略，而不只是 VBS？ | 五个对照（旧库策略、SBS、新成员单独、新库 VBS、新库实际策略） | 沿用下一阶段 §2；生成成本全部计入 |
| E4 执行反馈：学得的执行用时能否减小规划—实际误差并改善调度？ | 规划/实际 makespan 误差、仿真中的完成时间 | 仿真结果不外推为实车 |

数据划分：荷兰田块与 ee_field_130 已在历史研究中使用，只作开发；其余爱沙尼亚与立陶宛田块作为封存测试候选，在协议冻结前不运行求解器、不看结果。`paper` 分支预注册草案 v0.9 以 PyVRP 为回退基线，若导师同意把覆盖配置选择纳入主线 A，需要先修订并冻结协议，再一次性运行封存测试。统计沿用预注册：配对 Wilcoxon、Hodges–Lehmann 效应量与按田块自助法区间，负结果同等报告。

## 8. 边界

当前执行限于仿真中已适配的同构差速车型；地面摩擦与定位误差是未标定的合成参数；覆盖“可行”指通过项目独立检查（足迹、采样曲率、内缩区覆盖 ≥90%），不代表真实机具作业质量。试探结果、失败与异常均保留原始记录，不以学习曲线或 VBS 上界替代实际策略结论。
