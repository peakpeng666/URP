# 覆盖范围与来源

本分支是无旧历史的增量保全包。主文件布局对应本地主工作区的新增/修改文件；不同工作树候选放在 `preserved/worktrees/`，未自动合并。

| 来源 | 已保全范围 |
|---|---|
| 主工作树 | `snapshot/files.json` 的 406 项；包含进化模块、15 个测试、5 份计划、看板、报告、10 个结果 ZIP、稳定未提交记录与题录元数据 |
| 7 个关联工作树 | 当前有差异的文件、已暂存/未暂存成果，以及 425 个虽未检出但在现有 Git 对象中可读的文件版本 |
| Claude 项目交接 | 4 份项目进度/接续文档，位于 `preserved/handoffs/` |
| 外部 URP 浏览器测试工程 | 测试源码、各轮保留版本、轻量 JSON/文本报告，位于 `preserved/e2e/`；这些报告属于历史记录 |
| 导出与交接辅助脚本 | `preserved/imports/`，没有执行下载或恢复脚本 |
| 进化原始结果 | 29,051 份 JSON 全部计算 SHA-256；22,427 份与既有 10 个结果包逐项一致，另 6,624 份收进补充 ZIP |

精确文件来源与发布哈希见 `additional-files.json`，原始结果逐项哈希见 `raw-evidence.json`。主工作树相对基底已核实没有删除/重命名；7 个来源相对各自基底也未发现 Git 删除/重命名。部分文件未在稀疏工作树检出，已从现有本地 Git 对象保全，这不属于删除；见 `not-materialized.json` 和 `deletions-renames.json`。

发现工作使用用户主目录、桌面、文档、下载、常见项目/工作树目录及已挂载用户数据入口的有界目录元数据。未发现另一个独立的 AgriAutoLab 本地源码目录。现有私有网盘挂载中有 URP 存档和科研绘图资料，仅列目录元数据，未为本次盘点下载其中材料。其他独立项目、个人资料、凭证库、聊天存储、环境和依赖树不在扫描/上传范围内。目录发现不是全磁盘内容扫描，也不保证穷尽未命名/未挂载位置。

`literature/阅读目录.html` 已在首批上传。只读核验：17,068,782 字节，637 条题录/阅读笔记 JSON 和页面脚本；没有 PDF/图像/ZIP/data URI/长 base64 载荷，全文凭证模式无命中。它不是论文 PDF 归档。

21 份新增 PDF 的私有交接包已保存且逐字节回读核对，通过公开再分发审查前不放 GitHub。另有浏览器原始截图/视频/trace 等约 1.348 GB 留本地待私有归档与隐私复核；2177 个原始项、2 个非 UTF-8 文本后缀项和1份私有来源清单的精确元数据列在 `additional-exclusions.json`。原始浏览器 trace 可含请求上下文，未随公有分支发布。

本轮没有启动任何新实验或本地开发。历史结果、静态检查和真实仿真验收各自保留原有范围。
