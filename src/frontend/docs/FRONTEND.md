# 前端设计与架构


## 1. 产品要解决的事

使用者是做过、审过或要复查这次实验的研究者。工作台要让人在一处完成：看懂结论 → 找到真实样本 → 回放装箱 → 理解第 500 项后的那一次选择 → 对照收益与风险 → 追到原始字节。

不做的事：不重跑 policy、不训练、不生成候选；不补造算法“思考过程”、概率、置信度或实时进度。

## 2. 组织母题：第 500 项的“道岔”

实验的结构本身就是一条轨道：0–500 项共享 BF 前缀 → 第 500 项处只扳一次道岔（继续 BF / 切到 EoH）→ 4500 项续行 → 事后才知道哪条更好（branch oracle）。界面所有视图都用这个结构定位：

- 时间轴是一条轨道，500 处有分岔标记；当前位置属于“前缀 / 决策点 / 续行”三相之一，始终可见。
- BF、BF→EoH、SELECTOR 的比较在 500 前共享 BF 状态；全程 EoH 从首项使用不同策略，界面单独说明，不能声称同状态前缀。
- 风险视图是“一条前缀轨道 → 三个未来”，同一个选择作用于三个未来。

## 3. 两种认识论视角（必须一眼可辨）

| 视角 | 默认 | 可见内容 |
| --- | --- | --- |
| 当时已知 | 回放默认 | 已到达物品、当前箱状态、已发生的曲线；t ≥ 500 时显示冻结选择与训练邻居 |
| 事后对照 | 显式切换 | 未来物品、完整曲线、两分支终值、oracle、后悔值 |

事后模式整页加“事后”标识条与不同的未来绘制样式（虚化/描边），并写入 URL。总览页属于历史视角，页内标注。

## 4. 信息架构

顶部（桌面）/ 底部（手机）五个入口，状态全部写入 hash URL，刷新、前进后退可恢复：

1. **结果**（`#/`）：一句话主结论 + 端点读数（确认集各策略平均终箱数点图）+ 训练→冻结→确认→风险流程 + 余地/胜平负 + 108 流分布 + 18 单元矩阵 + 组 bootstrap 分布（浏览器解码原始 `cluster_bootstrap.npz` 复算）+ 风险摘要（单列）+ 证据与局限。
2. **样本**（`#/samples?...`）：264 流表格，按 split/尺寸族/顺序/选择/胜负/搜索筛选；同一多重集的三种顺序成组显示。点行进入回放。
3. **回放**（`#/replay/<instance>?a=&b=&t=&view=`）：5000 槽位货架画布 + 近景箱 + 分岔时间轴 + 累计箱数/差值曲线 + 当前一步读数 + 解释面板（当前一步 / 第 500 项决策 / 事后对照 / 证据）。
4. **同前缀风险**（`#/risk`）：4 组 × 3 个未来；前缀/特征/邻居/预测/选择一致性在浏览器内核对；oracle 偏好反转标注。
5. **证据**（`#/evidence?file=`）：包完整性、三栏核验状态（包内历史审计 / 本项目核验 / 未覆盖）、文件索引与只读预览、浏览器内重算 SHA-256。

任何关键数值旁的证据标记打开“出处抽屉”：值 → 来源文件 → 字段/行 → SHA-256 → 核验范围。

## 5. 视觉系统

- 底色：页面 `#F1F3F1`（偏绿的冷灰，实验台面），面板 `#FFFFFF`，发丝线 `#DDE2DF`。不使用米色、渐变装饰、统一阴影卡片。
- 墨色：主 `#1B2126`，次 `#4F5A63`，弱 `#7D8790`。
- 策略身份色：BF `#2F6FB3`，BF→EoH（亦即训练 SBS 角色）`#D08317`。选择器用主墨色（它是决策者，轨迹等于所选分支）。全程 EoH 不占身份色：灰 `#7A7F87` + 空心菱形，并注明“不同启动状态”。事后 oracle：空心圆环 + “事后”字样，不可部署。均配文字或形状；未附独立 CVD/全对比度报告，不宣称该专项认证。
- 差值发散色：节省（负）`#1A7F4B` ↔ 变差（正）`#B5482F`，中点 `#ECEEEF`；格内总有数字。
- 状态：通过 ✓、待核验 ◷、失败 ✕、未覆盖 ○，均为图标 + 文字，颜色不单独表意。
- 字体：拉丁与数字用本地 IBM Plex Sans（表格/坐标用等宽数字），中文走系统字体栈（Windows 微软雅黑 UI、Ubuntu Noto Sans CJK SC、Apple 苹方），哈希/ID/路径用本地 IBM Plex Mono。字号阶：12/13/14（正文）/16/20/24/32/44。
- 动效只解释数据：物品落入箱、分岔展开、视角切换；`prefers-reduced-motion` 时全部改为瞬时状态。

## 6. 回放呈现

- **货架画布**：状态保留原始 5000 槽，按原始索引排布，仅画已经打开的箱；每槽一列，高度 = 已装体积/100。槽号不等于累计箱数。当前箱用三角标记与高亮列标出，画布按当前已见最大槽位增长，在固定视口内滚动并跟随当前箱；每行数量随可用宽度计算。
- **近景箱**：当前箱附近约 9–15 个箱，按真实装入顺序堆叠物品段，新物品落入；显示 `pre_remaining → post_remaining`。
- **当前一步**：第 t 项尺寸、槽位索引（0 基，与原 assignment 一致）、残量前后、可行槽位数（含空槽，另列空槽数）、累计已用箱数。
- **曲线**：累计箱数与 A−B 差值，已知视角只画到 t。
- **控制**：播放/暂停、单步、倍速、拖动、重置；0/499/500/501/5000 直达；键盘 ←/→（±1）、Shift（±10）、PageUp/Down（±100）、Home/End、空格。

状态来源：`core/replay.mjs`（`ReplayEngine` / `ReplayComparison`，逐步校验 pre/post_remaining、used_bins_after，终态校验 remaining 与体积守恒）。前端不自造回放语义；每个显示帧都是某个整数 t 的真实状态，播放时可跳帧。

## 7. 决策解释（t = 500，第 501 项未到）

显示记录值：31 维前缀特征（按 6 组渐进展开）、z 分数、5 个训练邻居（训练流 ID、族/顺序、两分支真实终箱数、平方距离）、两分支预测（邻居标签均值，可展开算式）、最终选择与平局规则。

浏览器内复算只作核对：由前缀物品 + 内核回放的 500 项残量重算特征 → 用冻结 mean/scale 标准化 → 对 144 训练行求平方欧氏距离 → 稳定排序取 5 → 求均值预测 → 比较选择。报告逐项一致性与最大偏差（浮点容差内），不替代记录值。平方距离不是概率或置信度。

## 8. 科学措辞约束

- 负的“选择器−SBS”表示节省箱数。
- 88.17% 是“收回 SBS 相对同前缀两分支事后 oracle 的可改善余地”，不是装箱效率提高。
- 全程 EoH 起点状态不同，不是同状态 oracle。
- 风险集单列，不并入确认收益。
- 区间是全局确认集的族内多重集组 bootstrap；筛选后的统计只给描述值，不套全局区间。
- 同组三种顺序不是三个独立样本。
- 包内历史审计 ≠ 本项目核验；未覆盖项明确列出。

## 9. 技术栈

React 19.3 + TypeScript 6.0 + Vite 8.3（npm，`package-lock.json` 锁定），d3-scale/array/shape 计算坐标（SVG/Canvas 自绘），fflate 解码 NPZ，@noble/hashes 在非安全上下文中回退 SHA-256，lucide-react 图标，@fontsource 本地字体。Vitest 跑纯逻辑单测（不依赖 jsdom：jsdom 30 需要 Node ≥ 24.15，本机为 24.11.1）。

状态：hash 路由 + `useSyncExternalStore` 小型 store，无全局状态库。数据：静态 `/data/*.json`，按需加载并缓存。产品使用 `src/data/api.ts` 的哈希加载与共享请求、独立消费者取消，controller 修订号阻止旧响应覆盖；框架无关 `core/data-client.mjs` 同时保留给独立接入使用。

WSL 挂载盘上的文件由 Windows 侧编辑时 inotify 不触发，开发服务对 `/mnt/` 路径自动启用轮询（`BPP_WATCH_POLL=0/1` 可覆盖）。

## 10. 实施顺序

1. 脚手架、设计令牌、外壳与路由；数据加载层。
2. 一条真实样本的读取 → 回放 → 解释（货架、时间轴、控制、当前一步、决策面板）。
3. 结果页与样本页（含从分布/矩阵定位样本）。
4. 风险页、证据页与出处抽屉；浏览器内哈希与复算核对。
5. 手机布局、键盘/触摸/缩放/减少动效；浏览器截图验收（360/390/430/1366/1920）。
