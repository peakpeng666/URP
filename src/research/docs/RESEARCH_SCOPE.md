# 研究模块

| 模块 | 输入与实现 | 已有结果 |
|---|---|---|
| 父代选择 | 固定候选档案、行为分组与选父规则 | 9个候选槽的离线回放；后代生成与最终质量属于下一环 |
| CVRP选择与CRC | 24实例、432条历史求解记录；每折12训练、6校准、6测试 | 主α=0.10小于修正下限1/7，全部回退；0.25秒kNN平均改善0.01441% |
| 转弯mode | 服务方向、固定分配/顺序、mode与路径优化、原图检查 | 36例与原图精确解一致；重置方向的对照32例被拒绝 |
| NAS保真度 | 固定8结构的训练轨迹、独立重训与检查点 | 恢复、核验、统计重算、可选训练；详见[NAS接口](NAS_FIDELITY.md) |

当前CLI实现上述机制的恢复和复验。完整成果见[实验进度](../../../experiments/状态.md)，任务宿主与生成循环的接入见[下一阶段](../../../下一阶段.md)。
