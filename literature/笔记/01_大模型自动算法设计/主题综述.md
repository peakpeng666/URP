# 大模型自动算法设计

生成可复用算法组件。

## 方法脉络

| 文献 | 机制与用途 |
|---|---|
| [P026](<逐篇笔记/P026.md>) | 用输出对象区分优化器、预测器、提取器和设计器；搜索方式另列。 |
| [P177](<逐篇笔记/P177.md>) | 思想与代码成对，E1/E2探索、M1修改、M2调参、M3简化，执行评分后保留候选。 |
| [P321](<逐篇笔记/P321.md>) | 固定宿主内演化函数，按实例表现分簇，岛内选父与周期重置维持搜索。 |
| [P416](<逐篇笔记/P416.md>) | 短期比较与长期反思影响后续生成。 |
| [P252](<逐篇笔记/P252.md>) | 结构生成与数值配置分工，HPO费用单列。 |
| [P430](<逐篇笔记/P430.md>) | 实例画像匹配局部档案，实际运行对应专长算法。 |

共同接口是“规格与历史反馈→候选程序→执行评价→保留或改写”。需要比较的变量是表示、父代选择、反馈内容和评价预算。单个候选的平均分、库的互补性和上线推荐效果分别测量。
