# P455 CVRP快速算法选择＋配置，已有层次式近邻

文献：Selecting Fast Algorithms for the Capacitated Vehicle Routing Problem with Machine Learning Techniques (Asin-Acha et al 2024)

原文：[Selecting Fast Algorithms for the Capacitated Vehicle Routing Problem with Machine Learning Techniques (Asin-Acha et al 2024)](<../../../../papers/Selecting Fast Algorithms for the Capacitated Vehicle Routing Problem with Machine Learning Techniques (Asin-Acha et al 2024).pdf>)

## 输入输出、算法范围

研究单位需求CVRP：单仓库、同质容量、车数不设固定上限，以总路线长度为目标。原CVRPLIB需求被改为1、容量重新抽取，不能将结果说成未经改造的标准CVRPLIB成绩。选的是“很快生成可行初解”的程序，而不是给完整HGS充分时间后的最优算法。

三候选：
- FILO实现的Clarke–Wright savings，近邻k=100，节省值d(D,i)+d(D,j)−d(i,j)，可行时合并路线
- HGS仅跑到第一条可行解，95%运行来自初始种群第一候选，其他多为第2/3候选；不执行完整遗传搜索到通常停止条件
- MSA可配置sweep：用r∈[0,1]决定以仓库为中心的近/远两组；组内按极角扫过容量分车，单车TSP用Concorde里的Lin–Kernighan启发式。r不是神经模型参数，是求解器实例特定配置

HMS在预测前提取统计特征，RF选3类；若选sweep再调用GB配置器，预测100个离散r的归一化目标，取预测最好的4个逐一真求解后保留最好，形成4-MSA。选择与配置分层，避免将所有算法×参数组合拉平成大量类别（p3、6–7、10、12–13）。它没有生成新的算法代码。

## 推荐器可观察信息与训练标签

p10特征：客户数、容量、仓库到客户质心距离/仓库到最远客户距离、最少车数、10同心环的客户比例。都是求解前可得信息；无运行轨迹和未知最优值输入。归一化目标为(obj(i,r)−min_r obj)/(max_r obj−min_r obj)，min/max由训练时实际运行100配置得到；不能上线时先知道。max=min的退化处理正文未说明。

标签在§3.4明确按CW/HGS/VSw中最小目标，平手偏向更快；VSw是事后100配置最好。图3/其他段落有“best configuration”及MSA措辞，而最终部署实际是有限预测的4-MSA；是否在HMS训练时重建为真实4-MSA表现标签不够明确，须保留“理想配置标签与实际配置器存在可能错配”。没有代码不能宣布已证实程序错误。

选择器为RF(gini,200树)；配置器为GB(squared_error,learning_rate=.1,100估计器)，训练集5折grid search挑模型；分类准确率与配置MSE各自优化，并非直接端到端优化最终选择regret。p6对配置MSE的自然语言与p10的100维输出需一同读，不能当成直接回归最优r。

## 数据、成本及失败分母

训练：三类TSP生成器各500共1500几何实例，n20–15360、均2547；3仓库位置×4容量派生18,000 CVRP实例，L1/L2分别评。容量随机范围[1,√n]，不是[1,n]（p8原图）。几何共享派生实例在5折内是否按源实例隔离未说明。

测试：公共CVRPLIB多族，需求与容量经过上述改造；除AGS均n≈263，AGS均n≈12,200。训练/测试来源不同确是优点，但新约束、异质需求或农业几何并未测试。

p9正文称264测试实例；图2和表7为262；p8列表里E13/P23与表7E11/P24不一致，正文未解释完整筛除流程，不能填造缺失样本原因。HGS在部分>10000客户训练实例、多数AGS测试实例1小时内连首条可行解也不给；p8明确表3运行时间不计这种失败。训练集表3HGS约169/167秒、Sw约.504/.451秒、CW约2.156/1.909秒，因此“快算法”不等于所有实例都可实时。

标签生成至少每训练实例跑100sweep配置＋CW/HGS；这份离线成本不能与毫秒级RF查询混为一谈。特征提取被称便宜，模型图4–5显示低预测耗时，但本文没有完整HMS特征＋选择＋4次配置运行＋失败罚时的统一成本账。4-MSA比1-MSA近四倍运行不能默认为免费。

## 结果：真正选择可有效，准确率不是效益

VBS是固定候选的事后最好；m_a是逐实例obj_a/obj_VBS的均值，最优为1；规范化剩余差距mhat=(m_s−m_VBS)/(m_SBS−m_VBS)，0最好、1等SBS。不是路径最优值近似保证。

表7：L2总体4-MSA约1.02、CW1.07、HGS1.02、HMS1.01；L1分别1.02、1.07、1.04、1.01（仅两位小数）。HMS最好解命中64.89%/59.54%，独立报告的分类准确率64.50%/54.20%不完全同一数；平手定义/标签差异可能相关但原文未解释，不能强行配成一致。

作者报告HMS剩余SBS–VBS差距0.5(L2)/0.74(L1)，对应闭合约50%/26%，不是质量提升50%/26%，且不能从已四舍五入1.01/1.02重算0.74。所谓“离最好1%”是库内VBS，绝不是距真正最优1%。

最强反例：Li风格化放射几何上HMS仍约1.05/1.06；L1 F上HMS1.05而CW1.01；多个族单算法胜过HMS。因此结果支持组合平均获益，不支持逐例安全改进。部分误选只因各算法质量接近，所以低准确率未必高决策损失（p13图7与分析）。

sweep配置方面，p=1仅略优于固定最好r；多试配置扩大收益，p≥4边际差异小、p>10二者接近（p11–13）。强简单固定配置/多试对照必须保留。p4/表1/表4表明r≈0本身十分强，学习收益不能只与任意默认值比。

## 评估与解释的保留

- §2.7将SBS定义为训练集最好，p14却以测试集均值认定4-MSA是SBS，存在定义口径切换；可报告作者结论同时保留测试选SBS的差异
- 4-MSA的p=4来自所展示测试集上速度质量权衡，然后用于同套测试HMS；若无另独立最终测试，流程后选择可能产生乐观性。这是阅读者的方法学疑点，不称已查明实际泄漏
- 原文多次“significant”未同时给出成体系的重复种子、配对统计检验/区间；不将其翻成统计显著保证
- 层次架构允许调整局部模块是作者设计论点，但无新增算法零样本接入实证。加入算法仍需选择层训练标签/模型更新，模块化≠自动冷启动

## 对研究问题的判断

R1：误选可从离线全矩阵诊断，但不会自动说明缺算法；已有候选的可识别互补性需要改善。R2：算法选择＋参数配置及实际HMS早有CVRP直接先例，必须比本类强经典系统提出更窄差异，不能只画两层框架。R3：参数/算法新增可模块化更新是假设性工程便利，真实成本、分布外风格化实例和失败处理依然要测。

农业项目可迁移求解前廉价结构特征、决策损失优先、运行预算意识；不能迁移单位需求/欧氏或曼哈顿距离为转弯、补给、覆盖宽度的替代。第一可行HGS与完整HGS分别列基线。
