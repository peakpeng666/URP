# 校准与拒判

定义概率事件与拒绝动作。

## 方法脉络

| 文献 | 机制与用途 |
|---|---|
| [P116](<逐篇笔记/P116.md>) | CRC在明确损失与可交换性条件下控制边际期望风险。 |
| [P346](<逐篇笔记/P346.md>) | 温度缩放用独立校准数据校正分数。 |
| [P456](<逐篇笔记/P456.md>) | SelectiveNet同时学习预测和选择，以风险—接受比例衡量。 |
| [P117](<逐篇笔记/P117.md>) | Learning to Defer联合考虑机器错误、专家错误与转交费用。 |
| [P173](<逐篇笔记/P173.md>) | Jev级联的效果取决于任务、阈值、伙伴模型和费用。 |
| [P101](<逐篇笔记/P101.md>) | 分布偏移会改变不确定性估计的可靠性。 |

“某算法最好”“预算内可行”“相对回退有收益”是不同预测事件。拒绝后采用的算法和成本属于最终策略；全部回退可以满足保守规则，也可能完全失去选择收益。
