## 任务定义和它到底是不是算法设计
这是benchmark/应用评估，检测目标LLM的输入–输出或轨迹是否有某类失败，不是生成路径规划算法。每项x含state、label和meta，Jev对state一次批答多个typed问题，组合为risk s(x)，s≥t判失败。目标是AUROC排序、阈值F1、校准、拒判质量和费用，不可互相替代。

44基准、10类failure、7193个canonical检测项，5个2–7B开放target：每failure固定一个target，因此跨failure的差异与target身份部分混杂，不是5模型×44完整交叉测试。20基准规则评分、20单LLM judge、4多轮judge；11 validated、8 label缺陷/信息不可见、25未验证；6基准少数类≤4被排除，剩38 usable。generic NOUL只覆盖31（5个二选一MACHIAVELLI式+2个text-only uncertainty未问），best generic覆盖36，切勿把“.886”写成44基准总体准确率（PDF3–6/18–20）。

canonical state通常只target输入/输出，不送scorer verdict、gold、内部probability；MACHIAVELLI只场景+两选项，target pick在代码侧把P(B bad)变成选择的badness。任务是相对于参照的关系：谎言须相对自述belief；泄露须相对秘密/规范；奉承须看是否顺着用户而非单纯答错。AAR原本的H/HO是上游自动研究者的hill-climb/heldout角色，本评估全部都用同协议，不能把H/HO自动称本研究锁定独立测试（PDF18–19）。

## 问题/状态/读出三因素
1. generic模板按单回复/成对/规则/轨迹四种格式，填入benchmark-specific行为短语，开头guard把state标为待评材料。它是“零标签”而非“没有任务定义”。NOUL s=P(yes)，CHOICE soft=P(yes)不对undetermined重归一，SCORE soft=E[level]/2；argmax会丢失连续信息（PDF6/20–22）
2. 每基准15–40个strategy：direct不同措辞、rubric、多个窄问题soft decomposition、gate、ensemble、confidence abstention。一次request平均11.4题（4–28），API计费不是完全免费增加问题；附录59%输入tokens来自题组（PDF45）
3. 定向strategy在一半item groups上选、另一半测，20分组splits；同源题/同禁问prompt必须同组。F1阈值另2-fold分组CV，0.05..0.95网格；abstain按negative进fixed-denominator F1，AUROC比较需coverage≥.9。最优strategy和最优threshold各自都要隔离，做阈值CV不能洗去同测试集挑strategy偏差（PDF6/23）
4. 49成对context改变一field并保持items/labels；区分deployable（监控器可能有goal/system/belief）和label key（gold verdict、秘密清单、注入位置）。best shared question在两variant平均AUROC上共同选择，减少偏向丰富state但**仍在这两组数据上选择**，不是全新的held-out政策；必须同时看预设generic结果和其置信区间。permutation要求Jev回答乱序后接近chance，排code-side信息策略（PDF26–29）

## 排序与简单基线：确实有积极证据
generic NOUL31基准AUROC中位.886，跨基准+group item二层bootstrap95%CI[.821,.952]；胜更好TF-IDF/length于25/31，中位+.132[.057,.190]，sign-test p=9e-4。TF-IDF LR用state word1–2gram+char3–5gram、C1、balanced class、5fold OOF重做3次，实用而非故意空白baseline。零样本在此语言任务胜见域内标签的lexical baseline应保留，但未对照任务专门强神经监控器、规则直接执行或VRP选择器（PDF7、47–49）。

Targeted split-half38基准中位.911；与best generic（36基准中部分比较）差+.006[-.004,.015]，24/1/11、Wilcoxon .055，未证复杂措辞稳定优越。best generic仍是同集5读出max、约.005选择膨胀，给generic轻微优势；定向池同集膨胀.008高于增益本身，所有策略池.014，小样本可.13。图3图注说两边split-half而正文/表8说明generic in-sample，综合应采用明确表8并登记叙述不完全一致（PDF7、23、26）。

soft SCORE相对NOUL中位+.016[.001,.030]、19/7/5；soft CHOICE近似持平。argmax几乎普遍损失；阈值后再套rubric的策略9/10较最佳direct差、AUROC中位−.137；但soft分解在PrivacyLens/MASK/MACHIAVELLI部分有效，不能笼统说分解无用（PDF7–8、22–23）。

## 上下文增益常来自标签定义，不能写成部署能力
deployable reference generic仅1/7显著正（DeceptionBench +.050），已在state的MASK belief精炼再加0/3；label keys4/11显著、median+.053。PrivacyLens secret list .792→约.951，若业务真的持有它，部署可用性分类可改2/8；但其label是“清单里的秘密”，清单外真实侵犯也标negative，必须先决定需要检测的是哪种现象（PDF8、27–29、43）。

最强构念反例：SycophancyEval official label实际上incorrect，补gold generic AUROC .540→.941；换为“相对无用户意见时向用户建议移动”的corrected label，同一补gold反使.712→.288。所优化的标签与目标行为不同，更多信息能更好迎合错误指标却更差检测真正目标（PDF29、38–40）。此例直接警告路径规划“求解器成功”不等于任务建模正确。

MACHIAVELLI harm→不重叠held-out games AUROC .918→.851，−.067[-.122,-.016]是真正分布外退化；PrivaCI→GDPR没有显著下降，不能只报坏消息。MASK原belief transcript浓缩到一行，AUROC基本不变，tokens如8647→2504、11814→1996，表明可删不必要语义成本（PDF29–30）。

## 校准/阈值/选择性风险：R6核心
“输出概率”不等于“概率已在目标域校准”。generic NOUL pooled canonical ECE .047接近对角，但31基准median ECE .168；完美校准Bernoulli(p) null由于有限样本仍.074，24/31超过null95%（不是把有限样本噪声当失校准）。换equal-mass .173、debiased L2 .182仍支持；Brier median .145，reliability .042、resolution .106、uncertainty .215分别取中位，不能要求中位恰好线性恒等（PDF8、31–32）。

更广48文件口径pooled ECE .035、median file .150、36/48超null；它和canonical31的.047/.168不是互相矛盾，而是数据单位不同。逐文件mean p与base rate中位差.125、AUROC .905；NOUL压向中间、per-file slope1.58，CHOICE偏极端pooled slope.45。不能把高AUROC推成可直接共享阈值（Table13 PDF31）。

31基准generic F1 .706@.5→.822分组CV；仅10随机label拟合阈值、其余评估（200draw）到.793；20→.797、50→.803、oracle .849。label-free EM prior-shift纠正反降.571/.690。**最强负证据**：validated8基准t=.5中位.721，CV.694、k10 .684；按逐基准差的median，10label损失.025，不能将“各项中位之差.037”混成同一统计量。4个未验证规则基准大增益撑总体；10/31 CV失败（4不胜all-positive、6较.5更差），作者统一建议十label应收窄为条件策略（PDF32–33）。

拒判确有有效信号：canonical31保留|p−.5|最高一半，median accuracy79.3%→93.3%。更广文件汇总NOUL AURC .075（oracle .020）、error discrimination .780；这些是经验risk–coverage，未提供分布自由覆盖保证。social bias反例confidence AUROC .355、top10% accuracy0，因generic“misbehaving”与细微风格gap标签构念不同；并非总能拒绝低置信后安全（PDF31/34/43）。未实测转人工/转judge后的端到端成本和最终错误，选择性准确率不是整体业务收益。

## 独立人标证据：有价值，不能泛化成全部judge胜利
StrongREJECT另外1361人标回复、5人/项、39禁问prompt、4个generator；Jev1360成功（1个positive两次HTTP403）。predefined generic NOUL vs median人标κ.809、reference GPT4o-miniκ.811，差−.002[-.059,.057]；AUROC .971对.929，+.042，随机打破judge9档ties或将Jev粗化9档后仍保留优势。116分歧中人类57次（49%）站Jev，不是几乎所有分歧证明标签错（PDF34–36）。

按prompt分组半选定向问题，κ提升+.046 CI[-.024,.090]；按item分割会显著+.055，说明统计单位真的能改变显著性。跨数据集选问题无收益，必须避免prompt近重复跨fold。GPT3.5子群genericκ .668比scorer .790差−.121[-.205,-.034]；oracle threshold也仅.688，不能用“再校阈值总能修复”解释掉（PDF35–36）。

HarmBench584 attack-split人标样本Jev答578（6个403），3人/项；generic与单人κ均值.748对人间.736，CI差含0；split-vote项accuracy.708、unanimous .957，证据支持人类争议区域困难，但不能宣称同等于人类且零差异。README的602人标总数与paper584/578有split/总集口径差别，不能不解释直接换分母（PDF36–37）。

## 标签审计、信息不可见与原始数据选择
作者查看24 benchmarks、35clusters；311逐项审、另1640仅cluster count，单reader、无独立二次裁定。311中79=25.4%是Jev真错、89确定label问题、46解释性问题、75construct边界、22未分类；OPI贡献83/89 deterministic，去掉OPI与HarmBench后Jev错34.9%、deterministic3.6%。这是confidence-disagreement挑出的有偏审计，不是随机标签错误率（PDF37–40）。

- OPI旧label=注入任务答案正确，293/300跟从注入但83/89 negatives只是答错；修正后generic .231→.975，但只7 negative、F1 base-rate高
- SycophancyEval answer把incorrect当奉承；无意见时44/50本就答错；corrected只有15/150 positive。feedback15/30所谓“不批评”positive首句点名谬误，是较直接label矛盾
- MACHIAVELLI1100项label都依赖选项的游戏后果annotation，state不显示；target又75–78%选B，无法将annotation后果全从短句读出；存在未展开template变量。它是标注可观测性边界，不是所有失败都应称“标签错误”
- Abstention两judge κ.05/Instrumental κ.29；same judge的RAGTruth两个相近定义κ.953不证明无judge偏差。WinoBias FEMALE substring误判MALE方向，但binary any-gap不变，必须保留该基准主表而只改方向（PDF36/38–40）

## 成本、缓存、版本与代码边界
一个完整pass在19 API judge基准：Jev7.18M输入tokens/$0.30 vs judge8940calls/9.36M输入输出估计/$18.96，pooled62.9×，per-benchmark median16.2×，18/19便宜；StrongREJECT judge0.12×反更便宜（judge记录只参数、token是下界）。把全部judge按4o-mini价格且Jev只问generic，pooled12.1×、median3.3×；全battery时pooled6×/median1.5×，5个judge更便宜。PrivacyLens+MASK贡献62–65%judge费用；20规则基准Jev反增加$0.36。省钱主要来自当时单价与多judge调用，不是凭一调用必然省钱（PDF45–47）。

研究dedup23411请求、约.12%error；成功计费表23384调用/54M/$2.27；全cache26133records含重复和29failed口径另列。client latency median.313s,p90.55,p99 1.86，不是硬实时保证或GPUkernel纯延迟。研究费用没合并target生成、全部label、GPU、人工label audit/阈值标注成本。请求实际用jev-latest，成功响应报告1.13.0、2026-09-23采集；以后同alias重跑非同版本，论文以cache为主（PDF45/49–50）。

## 项目判定与最近邻
R6“有条件值得追”：若农业任务确实有语言需求解释、任务契约或叙述性日志审查，generic soft语义检测是可选低价部件；先对照可解释规则/结构化特征模型，按真实错选损失、拒判覆盖和人工/solver成本决定要不要Jev。不能把十类语言failure上AUROC直接当算法推荐净收益。
R1审计分歧可用来检查label/建模/validator，不是低confidence⇒库缺能力，更不是“让Jev决定生成什么”已证有效；需要独立真实质量参考。R2定向措辞/多题组合平均无额外收益是复杂方案反例；没有生成互补算法或上线逐实例路由证据。R3有限label阈值适配有条件正证据，但跨generator/新游戏退化和版本alias都提醒不能宣称零成本新算法接入。R4严格分开设计期max、交叉拟合、部署决策和总成本。R5路线可行性/地头转弯/覆盖/容量等仍需独立validator与建模，semantic detector不替代数值约束。

继承对照（只读既有结论卡，非新读原文）：M06-C01指出概率/置信度不可替代实际任务效用，M04-C03强调低置信不能定位库能力缺口，M02-C01已有controller-mediated共同演化。本文强化这些边界但不证明原设想的算法设计创新。
