# P528 TTT分布 固定实例的随机运行，不是跨实例排名

文献：TTT Plots - A Perl Program to Create Time-to-Target Plots (Aiex et al 2007)

原文：[TTT Plots - A Perl Program to Create Time-to-Target Plots (Aiex et al 2007)](<../../../../papers/TTT Plots - A Perl Program to Create Time-to-Target Plots (Aiex et al 2007).pdf>)

全部11页含参考文献通读，页2–9图/公式/工具表原页核对。目录2007刊年与所供2006修订技术报告版本区分。

## 对象与计算
固定instance/target，重复运行随机算法n次，每次不同seed，记录首次达到目标（不差于给定目标函数阈值）的CPU时间。时间排序t_(i)，赋绘图位置p_i=(i−.5)/n，画横轴时间、纵轴达标概率（页1–2）。这与严格经验CDF在每点i/n不同，但均是经验分布可视化；图本身不要求先知真最优，目标可为有意义的次优阈值。主要推断单位是同一实例内随机运行，不可用这些seeds代替独立实例族（P479/P515）。页9也提到另有在随机实例各跑一次的用途，但那混合了实例变异，分布含义不同。
工具额外拟合两参数移位指数F(t)=1−exp(−(t−μ)/λ)，t≥μ且t<μ为0。QQ横轴−ln(1−p_i)，纵轴时间，拟合线λx+μ；用四分位间斜率和截距抗少数离群，不是OLS。标准差近似σ_i=λhat sqrt[p_i/{n(1−p_i)}]（页3）。原文页2称λ为分布均值，但移位后的均值应μ+λ、SD=λ；页3上下四分位分别写Q(.25)、Q(.75)颠倒。这些是符号/描述问题，不能原样传播为数学定义。
不同seed仅是作者独立性假设的操作方式，不保证任何PRNG/状态共享设置独立。经验TTT可在指数不拟合时依然有用；指数形式是研究假设与若干局部搜索观察，并非所有启发式/LLM搜索必然服从的定理。若含非零永不成功概率，CDF上限不为1，不能强拟合本文完整指数模型。

## 工具与示例
输入.dat每行CPU时间，Perl生成经验/理论TTT、QQ及上下1SD共10文件并调用gnuplot输出PostScript（页5表1）。本次只读论文，未取得/审计/运行tttplots.pl，不能声称代码已复现。示例单个MAX-CUT G13、GRASP+path-relinking、目标572，展示n=10/20/30/50/75/100/125/150/200曲线（页6–8）。作者观察n200拟合好、目标过易会集中近零；这不是任意项目需要200seeds的功效结论，也不应为拟合漂亮而删去容易任务。

## 统计边界
作者明确页3–4：QQ±1SD是相对变异可视化，不得作正式拟合检验；相邻排序点高度相关，同时查看所有点的越界率比单点大。也不是算法性能差的置信区间。工具描述未给右删失/失败编码，若预算内未达标不能扔掉然后对成功者归一，否则夸大成功概率与速度；应保存所有运行、预算和删失指标，具体生存分析方法需另行制定。

## 项目意义
R1：区分不合法、合法未达标、超时，TTT只针对已定义且验证有效的达标事件，不解释哪个能力缺失。R2：给实际选择器和每候选算法画多个预设目标的达标概率曲线；P088跨实例相对最优观测时间profile与此互补，不能混写一个统计样本。R4：CPU时间需标硬件/并行度；算法生成、编译、选择、特征成本若任务端到端有关也须纳入另一个总时间口径。LLM搜索不一定独立同分布，重启/缓存/自适应历史要记录。农业路线阈值还需先过可行性与覆盖检查。
