# 算法库生成与推荐协同 文献比较

## P168 EoH-S - Evolution of Heuristic Set Using LLMs for Automated Heuristic Design (Liu et al 2026)

- 类型：方法/集合生成
- 方法：CPI贪心互补保留+互补父代提示+局部改进
- 生成对象：Python构造启发式集合
- 评价方法：训练实例负gap向量；集合逐实例最好
- 搜索方法：LLM进化，CS/LS
- 反馈：性能向量与父代代码
- 预算：2000次评价；种群10；3次搜索；作者<2h
- 实验：OBP/TSP/CVRP，外部BPPLib/TSPLib/CVRPLib
- 限制：VBS非选择器；统计/总成本缺账；部分正文与表数字冲突
- 与项目的关系：R2集合构建强近邻；R1实际失败归因未覆盖

## P248 Illuminating Heuristic Design - Language-Model-Driven Quality-Diversity Evolution for Combinatorial Optimization (Chen & Liu 2026)

- 类型：方法/结构化生成库+实际选择
- 方法：MAP-Elites SHAP-AST档案+实例赢家亲和最近中心
- 生成对象：完整启发式程序
- 评价方法：gap/time/CV三目标；真实评价器未随参考demo提供
- 搜索方法：50种子+500代LLM变异/交叉
- 反馈：SHAP结构反馈与三目标；不含上线失败诊断
- 预算：作者约500调用$85/轮；30轮$2550；50+500计数不一致
- 实验：CVRP/VRPTW/TSP/JSSP静态与扰动/随机/动态；实际selector宣称
- 限制：占用与QD-score上界冲突；mock不支持性能；符号/重投影/亲和缺链
- 与项目的关系：R2机制强近邻但定量证据降级；R1上线生成反馈属未来
