# P067 Transformer：注意力、结构与训练

文献：Attention Is All You Need (Vaswani et al 2017)

原文：[Attention Is All You Need (Vaswani et al 2017)](<../../../../papers/Attention Is All You Need (Vaswani et al 2017).pdf>)

## 身份与要解决的问题

题名：*Attention Is All You Need*。作者：Ashish Vaswani、Noam Shazeer、Niki Parmar、Jakob Uszkoreit、Llion Jones、Aidan N. Gomez、Łukasz Kaiser、Illia Polosukhin。正式会议年份为 **NIPS 2017**；本地文件为 **arXiv:1706.03762v7，2023-08-02，15 页**，不是一篇 2023 年新提出 Transformer 的论文。【P067，PDF 第 1 页；[arXiv 版本记录](https://arxiv.org/abs/1706.03762v7)】

这篇论文的具体问题是序列转换，主要实验是机器翻译：给定一句输入，生成另一种语言的输出。此前常见模型用循环网络逐位置计算隐藏状态，句内计算难以充分并行；远距离信息也要经过较长的计算路径。Transformer 用注意力建立位置间的直接联系，替代序列对齐的循环和卷积模块。【P067，PDF 第 2 页，§1–2】

作者没有首次发明所有形式的注意力。贡献是把自注意力、多头投影、前馈网络、残差、归一化、位置表示等组合为完整的编码器—解码器，并给出有竞争力的训练与实验结果。标题也不表示模型只有注意力一种计算。

## 从零开始：输入、输出、训练对象

把一句话拆成 token。Token 是词、子词或符号等离散单元，不一定等于一个汉字或一个完整单词。Embedding 则把 token 编号查表转换为一串数字，得到模型使用的向量。

输入是 \(x=(x_1,\ldots,x_S)\)，输出是 \(y=(y_1,\ldots,y_T)\)。编码器把输入变为上下文表示；解码器依据输入和已经生成的前缀，预测下一个输出 token。【P067，PDF 第 2–3 页，§3】

下式是对其自回归训练方式的教学形式化，论文没有把它列为一个新的编号公式：

\[
p_\theta(y\mid x)=\prod_{t=1}^{T}p_\theta(y_t\mid y_{<t},x),\qquad
\mathcal L(\theta)=-\sum_t\log p_\theta(y_t\mid y_{<t},x).
\]

\(\theta\) 是模型中的可训练参数；\(y_{<t}\) 是此前的输出；训练通过梯度改变 \(\theta\)。论文还采用 label smoothing，因此实际目标不完全等于只奖励一个正确 token 的普通 one-hot 交叉熵。【P067，PDF 第 7–8 页，§5.3–5.4】

**与上一篇 P026 的区别：** 本篇在训练一个生成模型的权重；P026 中不少算法设计系统固定模型权重，只搜索外部程序。二者可以组合，但完成一个过程不能自动算作完成另一个过程。

## 沿着架构图走一遍

原始 base 模型的编码器有 6 层，每层两个子层；解码器也有 6 层，每层三个子层。各层结构相同不代表它们共享同一组参数。【P067，PDF 第 3 页，§3.1、图 1】

| 所在位置 | 子层 | 它要完成什么 |
| --- | --- | --- |
| 编码器 | 自注意力 | 每个输入位置从其他输入位置收集信息 |
| 编码器 | 逐位置前馈网络 | 对每个位置的特征做非线性变换 |
| 解码器 | 带因果掩码的自注意力 | 当前输出只能访问允许的输出前缀 |
| 解码器 | 编码器—解码器注意力 | 根据当前生成状态，从输入表示里取信息 |
| 解码器 | 逐位置前馈网络 | 进一步加工每个输出位置的特征 |

每个子层都有残差连接和归一化。原始模型使用后置 LayerNorm：

\[
z=\operatorname{LayerNorm}\big(x+\operatorname{Dropout}(\operatorname{Sublayer}(x))\big).
\]

论文 §3.1 的简式省略了 dropout，§5.4 补充其位置。这里把两处说明合起来写。残差要求相加张量形状一致；base 的模型维度为 512。【P067，PDF 第 3、8 页】

后续看到 Pre-LN 时，要与这个原始 Post-LN 顺序区分。归一化为什么影响训练稳定性，将在 P288/P349 中继续读；本篇没有提供那两篇的理论分析。

## 核心公式：注意力就是“算权重，再汇总信息”

论文公式 (1) 为：

\[
\operatorname{Attention}(Q,K,V)
=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V.
\]

需要掩码时，在 softmax 之前加入掩码矩阵 \(M\)：允许的位置为 0，不允许的位置为 \(-\infty\)。这对应论文 §3.2.3 对实现的说明。【P067，PDF 第 4 页，式 (1)；第 5 页，§3.2.3】

Q、K、V 分别叫 query、key、value，可以暂时理解为：

- Q：“我现在想找什么信息？”
- K：“每个位置提供什么索引，怎样与查询匹配？”
- V：“实际汇总到输出中的内容是什么？”

这些是对向量运算的比喻，不是模型内部真的存着三句自然语言。Q/K/V 通常来自输入向量乘以不同的可学习矩阵。

### 形状逐步核对

先不考虑 batch。设查询数为 \(n_q\)，键值数为 \(n_k\)：

| 张量 | 形状 | 含义 |
| --- | --- | --- |
| \(Q\) | \(n_q\times d_k\) | 每个查询的向量 |
| \(K\) | \(n_k\times d_k\) | 每个键的向量 |
| \(V\) | \(n_k\times d_v\) | 每个键对应的值 |
| \(QK^\top\) | \(n_q\times n_k\) | 每个查询与每个键的匹配分数 |
| \(A=\mathrm{softmax}(QK^\top/\sqrt{d_k}+M)\) | \(n_q\times n_k\) | 沿“键”这一维归一化后的权重 |
| \(AV\) | \(n_q\times d_v\) | 每个查询汇总到的信息 |

没有 dropout 干预时，每行注意力权重和为 1。不要沿查询维做 softmax，也不要要求 \(d_k=d_v\) 才能进行这个运算；原论文具体配置取两者相同，但公式允许不同。

### 一次真正的手算

以下数值是本笔记构造的例子，已用独立算术核对，不是论文中的实验结果。

\[
Q=K=\begin{bmatrix}1&0\\0&1\end{bmatrix},\qquad
V=\begin{bmatrix}10\\20\end{bmatrix},\qquad d_k=2.
\]

第一行缩放后的分数是 \((1/\sqrt2,0)\)。对应权重为：

\[
\left(\frac{e^{1/\sqrt2}}{e^{1/\sqrt2}+1},
\frac{1}{e^{1/\sqrt2}+1}\right)
\approx(0.66976155,0.33023845).
\]

第一行输出为 \(0.66976155\times10+0.33023845\times20=13.30238451\)。第二行输出为 16.69761549。

若第一位置禁止看第二位置，第一行分数变成 \((1/\sqrt2,-\infty)\)，softmax 变为 \((1,0)\)，输出恰好为 10。这个变化可以直接检查因果掩码是否生效。

### 为什么除以 \(\sqrt{d_k}\)

论文脚注假设 q 与 k 的各分量相互独立，均值 0、方差 1。则每项乘积 \(q_i k_i\) 均值为 0、方差为 1，不同项独立，所以：

\[
\operatorname{Var}(q\cdot k)
=\operatorname{Var}\left(\sum_{i=1}^{d_k}q_i k_i\right)=d_k.
\]

点积的典型幅度随 \(\sqrt{d_k}\) 增长；缩放后方差为 1，可缓和过大的分数让 softmax 饱和的问题。【P067，PDF 第 4 页，§3.2.1、脚注 4】

这不是任何真实训练状态下都成立的严格分布定理。独立、零均值、单位方差是解释缩放动机的假设；训练后的分量可能相关。

## 多头注意力不是把同一结果复制八份

论文让不同头使用不同的可学习投影：

\[
\mathrm{head}_i=\mathrm{Attention}(QW_i^Q,KW_i^K,VW_i^V),
\]

\[
\mathrm{MultiHead}(Q,K,V)
=\mathrm{Concat}(\mathrm{head}_1,\ldots,\mathrm{head}_h)W^O.
\]

base 采用 \(d_{model}=512,h=8,d_k=d_v=64\)。每头在较低维空间中计算，拼接后回到 512 维，再做输出投影。【P067，PDF 第 4–5 页，图 2、§3.2.2】

对 batch 大小 B、输入长度 S 的编码器自注意力：

```text
输入                  (B, S, 512)
各头 Q、K、V          (B, 8, S, 64)
每头注意力分数        (B, 8, S, S)
每头输出              (B, 8, S, 64)
拼接并输出投影        (B, S, 512)
```

不同投影使各头能够处理不同表示子空间；“能够”并不保证每个头一定学成某个可命名的语法模块。附录只是给出了若干可观察实例。

跨注意力中，Q 来自解码器，K/V 来自编码器，输出长度 T 与输入长度 S 可以不同；分数形状为 \((B,h,T,S)\)。不能把这一步写成 Q/K/V 全部来自同一个序列。【P067，PDF 第 5 页，§3.2.3】

## 训练可以并行，生成为什么仍要逐步做

假设目标句为 `我 爱 你 EOS`。训练时：

```text
解码器输入：BOS  我  爱  你
预测目标：  我  爱  你  EOS
```

输入整体右移一位，配合因果掩码，保证每个位置无法读取自己要预测的答案或后面的答案。训练已有完整目标句，可以一次构造所有位置的计算；掩码限制的是信息流，不要求训练时逐 token 循环计算。【P067，PDF 第 3、5 页】

实际生成时，后续 token 尚未知，只能先生成一个，再把它加入前缀，然后生成下一个。因此，表 1 中自注意力层的顺序操作 \(O(1)\) 不表示整句自回归生成只需一步。作者在结论中仍把减少生成的顺序性列为未来工作。【P067，PDF 第 6 页，表 1；第 10 页，§7】

实现检查可以修改某个“未来”输入 token，再检查此前位置的输出是否保持不变。若前面预测改变，应检查掩码方向、右移或其他信息泄漏。

## 前馈网络、位置、参数学习各自负责什么

### 逐位置前馈网络

\[
\operatorname{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2.
\]

这是论文公式 (2)。base 中维度为 512 → 2048 → 512；同一层各位置用同一组参数，不同层参数不同。注意力混合位置之间的信息，FFN 加工每个位置的特征，两者承担的作用不同。【P067，PDF 第 5 页，§3.3、式 (2)】

### 正弦位置编码

\[
PE_{p,2i}=\sin\left(\frac p{10000^{2i/d_{model}}}\right),\qquad
PE_{p,2i+1}=\cos\left(\frac p{10000^{2i/d_{model}}}\right).
\]

位置编码与 token embedding 相加，而不是拼接。输入向量仍为 \(d_{model}\) 维。无额外位置信号的编码器自注意力对输入重排具有相应的置换性质，因此要显式注入顺序信息。【P067，PDF 第 6 页，§3.5；最后一句是对其结构的数学解释】

作者提出固定偏移可以用线性变换表示。令 \(\lambda_i=10000^{2i/d_{model}}\)，\(\delta=k/\lambda_i\)，由和角公式：

\[
\begin{bmatrix}\sin((p+k)/\lambda_i)\\\cos((p+k)/\lambda_i)\end{bmatrix}
=\begin{bmatrix}\cos\delta&\sin\delta\\-\sin\delta&\cos\delta\end{bmatrix}
\begin{bmatrix}\sin(p/\lambda_i)\\\cos(p/\lambda_i)\end{bmatrix}.
\]

这是对原文说法的展开推导。它说明表示具有方便的相对位移结构，**没有证明训练后的模型一定能泛化到任意长序列**。原文对此使用的是可能性表述；表 3 的学习式位置对照也不是长度外推实验。【P067，PDF 第 6、9 页】

### 权重共享与训练

原文说明其 embedding 与输出前 softmax 的线性变换共享权重，并在 embedding 中乘 \(\sqrt{d_{model}}\)。【P067，PDF 第 5 页，§3.4】具体复现仍要根据所用词表及实现确认哪些矩阵可共享，不能在不兼容词表上机械套用。

下面是教学伪代码，不是对原作者源码调用链的复述：

```text
先划分训练、验证、测试，并固定 token 化和词表
for 每个训练 batch (src, target):
    decoder_input = BOS + target 去掉最后一个位置
    memory = Encoder(src)
    logits = Decoder(decoder_input, memory, causal_mask, padding_masks)
    loss = 忽略 padding 的目标损失，并按所选规则做 label smoothing
    清空旧梯度
    反向传播得到梯度
    用 Adam 和当前学习率更新模型参数
在验证集选择配置与 checkpoint
配置固定后做最终测试，并单独记录解码设置
```

## 复杂度到底在比较什么

原文表 1 给出，自注意力的位置交互项为 \(O(n^2d)\)，循环层为 \(O(nd^2)\)。自注意力任意两个位置间的最大路径长度为 \(O(1)\)，循环模型为 \(O(n)\)。【P067，PDF 第 6 页，表 1】

阅读时需加上边界：

- 比较对象是表中相应层的主要计算；完整 Transformer 还要算投影、FFN 等，不能用 \(O(n^2d)\) 概括所有代价。
- \(O(1)\) 路径长度说的是网络连接结构，不代表模型必然学会长距离关系。
- 当 n 很大时，密集注意力的二次增长会变贵；常规实现还要存储随 \(n^2\) 增长的注意力分数。本句是由形状得到的实现分析。
- 原文表内卷积 \(O(\log_k n)\) 的路径对应其讨论的扩张卷积；连续卷积核的堆叠路径另见第 7 页说明，不能把所有卷积一概而论。

## 自测题与答案要点

1. **Q 为 3×4，K 为 5×4，V 为 5×2，输出多大？** 分数 3×5，输出 3×2；softmax 沿 5 个键的位置做。
2. **为什么解码器输入右移后仍需要 mask？** 右移阻止当前位置直接拿到自己的标签；mask 阻止从后面位置读取未来标签，两者配合。
3. **8 头是否把总表示维度从 512 变成 4096？** 原配置每头 64 维，拼接是 512，再输出投影；各头有不同投影参数。
4. **训练并行是否意味着可以一次独立生成所有输出词？** 否；训练有真实前缀并用 mask，生成需要先得到此前 token。
5. **表 3 的 25.8、表 2 的 27.3 与英法的 41.8 能放在同一列直接排高低吗？** 不能；语言、开发/测试划分、checkpoint averaging 等条件不同，且英法正文另有 41.0 的冲突值。
