# 预算分配与反馈学习

## 方法脉络

| 文献 | 机制与用途 |
|---|---|
| [P344](<逐篇笔记/P344.md>) | Successive Halving分阶段增加资源并淘汰低分配置。 |
| [P246](<逐篇笔记/P246.md>) | Hyperband用不同初始规模和保真度折中早期探索与深入评价。 |
| [P096](<逐篇笔记/P096.md>) | BOHB把基于密度的配置提议接入多保真分配。 |
| [P225](<逐篇笔记/P225.md>) | GEPA利用执行轨迹的文本反馈修改提示，并保持候选互补。 |
| [P154](<逐篇笔记/P154.md>) | Doubly Robust结合结果模型和倾向信息估计策略价值。 |
| [P533](<逐篇笔记/P533.md>) | UniRoute用新模型的有标签probe接入路由表示。 |

低保真的价值取决于是否漏掉最终优胜者，而非只看整体相关。记录候选执行、续跑、失败与全部配置成本。离线日志评价还需要支持集、倾向概率与数据隔离。
