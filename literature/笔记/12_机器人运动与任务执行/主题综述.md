# 机器人运动与任务执行

访问顺序到可执行运动。

## 方法脉络

| 文献 | 机制与用途 |
|---|---|
| [P347](<逐篇笔记/P347.md>) | Dubins以位置和航向为状态，在曲率约束下构造连接。 |
| [P362](<逐篇笔记/P362.md>) | Reeds–Shepp加入倒车动作，改变可用运动。 |
| [P505](<逐篇笔记/P505.md>) | OMPL以状态空间、状态与运动检查器、规划器组成接口。 |
| [P085](<../07_实例共演化与泛化/逐篇笔记/P085.md>) | Bench-MR统一地图、机器人几何和规划资源以比较运动规划。 |
| [P118](<逐篇笔记/P118.md>) | 地头规划的覆盖仿真与实机单圈实验分别提供证据。 |
| [P378](<逐篇笔记/P378.md>) | Hybrid A*将连续位姿与栅格启发式结合，后续平滑仍要检查障碍。 |

连接长度、几何可行性、车体扫掠和动力学执行分层验收。固定航向连接图上的最优顺序是一种明确子问题；图中无路径仍可能在更大的连续状态空间有解。

## 本项目进展

已完成72例固定航向Dubins排序及朝向A*验证；固定连接图中可行数由65/72增至67/72。尚无车体动力学和实机闭环实验。

[实验或代码记录](<../../../experiments/reports/服务与运动/Dubins固定航向排序.md>)。

## 后续工作

Dubins和朝向A*已有验证；车体几何、速度约束、跟踪误差与实机闭环需要后续实验。
