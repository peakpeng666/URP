# 路由模型与经典搜索

状态保留与经典搜索。

## 方法脉络

| 文献 | 机制与用途 |
|---|---|
| [P009](<逐篇笔记/P009.md>) | ALNS按历史表现调整移除/修复算子选择。 |
| [P343](<逐篇笔记/P343.md>) | 广义路由将分配、排序、服务模式与连接路径分解，并用模式优化保持方向状态。 |
| [P470](<逐篇笔记/P470.md>) | SISR删除相邻连续客户串，再带blink重建以释放空间和容量余量。 |
| [P231](<逐篇笔记/P231.md>) | GLS通过惩罚特征引导局部搜索离开当前局部最优。 |
| [P498](<逐篇笔记/P498.md>) | 转弯罚金改变连接状态与费用。 |
| [P504](<逐篇笔记/P504.md>) | 混合容量广义路由需要同时保留服务与转弯约束。 |

由弧到节点的转换要保留恰好服务一次、需求、方向及连接代价。逐对取最小转弯费用可能组合出不存在的全局状态。已有经典结构直接决定生成接口和强基线。
