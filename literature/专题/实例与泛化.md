# 实例与泛化

实例生成记录三层量：生成器输入参数、生成后的结构特征、各算法在固定预算下的表现。规模和结构变化可能改变求解难度，影响方向由实验确定。CVRPLIB X、农业基准田和实例空间研究提供设计方法。[P341](<../笔记/07_实例共演化与泛化/逐篇笔记/P341.md>)、[P052](<../笔记/07_实例共演化与泛化/逐篇笔记/P052.md>)、[P255](<../笔记/07_实例共演化与泛化/逐篇笔记/P255.md>)。

## 结构维度

| 维度 | 可记录的量 | 需要一起考虑的条件 |
|---|---|---|
| 行长异质性 | 行长变异系数σ(ℓ)/μ(ℓ) | 田界形状、服务需求和路线目标 |
| 连通结构 | 合法行端连接数/全部候选连接数 | 航向、障碍、禁止转弯与车辆几何 |
| 容量 | Q/总需求、需求分布、可行分趟数 | 仓库距离、固定费用与补给规则 |
| 仓库位置 | 到服务区域的距离、相对中心位置 | 容量与车辆数 |
| 路线规模 | 客户或作业行数、每趟服务数 | 算法结构、预算和实例族 |
| 转弯 | r_min/幅宽、连接代价异质性 | 起终姿态、倒车与地头空间 |
| 资源异质性 | 车辆、机具、速度及兼容矩阵 | 任务顺序与空间分配 |

行长变异系数为0、连接完整可以描述规整实例；这本身不证明问题平凡。容量放松会扩大可行域，但启发式难度不必单调。某个8行田块案例中的趋势需在新布局和不同求解器上另测。

生成器的分布也无需强行让所有算法胜率相同。性能分布偏向一个算法可能来自真实目标分布。应报告目标场景、特征覆盖和求解器分歧，并补充结构对照，而不是按想要的赢家比例筛实例。

## 泛化轴

| 测试变化 | 能回答的问题 |
|---|---|
| 同分布新随机种子 | 对该生成分布的新样本是否稳定 |
| 新几何或实例族 | 是否能迁到未参与开发的结构 |
| 新规模 | 计算资源与表示是否随规模适用 |
| 新程序谱系 | 选择器是否识别未见候选的能力 |
| 新原子约束 | 表示、动作和checker是否正确扩展 |

父程序和近似改写属于相关谱系；同田块的旋转、裁剪和参数变化也需要分组。要研究新实例与新程序同时出现，须在两条轴上留出。

## 共演化与外部测试

MOSAIC、ASRO和RAISE将算法反馈用于寻找有区分力或困难的实例。PLR重访当前策略尚能学习的环境。这些是主动设计训练分布的方法，最终效果仍用独立目标分布测试。[P327](<../笔记/07_实例共演化与泛化/逐篇笔记/P327.md>)、[P213](<../笔记/07_实例共演化与泛化/逐篇笔记/P213.md>)、[P407](<../笔记/07_实例共演化与泛化/逐篇笔记/P407.md>)、[P389](<../笔记/07_实例共演化与泛化/逐篇笔记/P389.md>)。

小实例保留为精确对拍集，大实例用于预算与扩展性。按算法表现定向生成的挑战集另行标记。真实地图、合成几何、固定连接图和实机任务分别记录来源与成功条件。

当前已有装箱留族、新20序列、VRPTW新几何、容量空间扩展和固定航向Dubins测试；完整实例—算法共演化尚待实施。结果入口见[综合分析](../综合分析.md)。
