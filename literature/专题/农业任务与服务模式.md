# 农业任务与服务模式

农业作业先按服务动作建模，再选择求解器。点位运输、完整作业行、面积覆盖和随主机移动产生的补给请求，分别对应不同任务。田间主作业与服务物流的区别见[P510](<../笔记/11_农业作业与覆盖规划/逐篇笔记/P510.md>)、[P511](<../笔记/11_农业作业与覆盖规划/逐篇笔记/P511.md>)；覆盖模块见[P203](<../笔记/02_算法库生成与推荐/逐篇笔记/P203.md>)。

## 输入与完成条件

| 对象 | 必须保留的状态 | 完成条件 |
|---|---|---|
| 点位取送 | 地点、需求、取送顺序、装卸规则 | 正确访问并完成取送 |
| 作业行 | 入口、出口、服务方向、需求、服务轨迹 | 整行按允许模式完成一次 |
| 面积覆盖 | 边界、障碍、作业宽度、地头、条带 | 指定区域达到覆盖要求 |
| 多机多趟 | 机具兼容、容量、补给位置与时间 | 分配、连接及每车日程共同可行 |

生成平行作业行时的整体朝向改变实例；沿某一条行从哪端进入属于服务模式决策。对行i定义模式集合Mᵢ，每个模式包含入口位姿、出口位姿和服务轨迹。单向服务时只有一个模式。节点转换若保留这些信息，也可以完整表达行服务。[P343](<../笔记/10_路由模型与经典搜索/逐篇笔记/P343.md>)。

在固定行集、不可拆分服务和固定补给点的一个容量模型中，每趟满足Σqᵢ≤Q。若各模式的服务长度相同，总服务长度是常数，总距离与非作业距离有相同最优解；方向相关服务成本、可变行集或拆分服务会改变这个关系。

## 模式不能逐对独立压缩

中间行B有两种服务方向。模式一的进入、离开代价为(0,10)，模式二为(10,0)。分别取两项最小值得到0；任意一致模式的实际成本均为10。连接成本因此应按有序状态c(i,a,j,b)存储，并在全路线中保持a、b的一致性。

弧到节点转换需保持三个关系：可行解能映射过去，转换解能还原，目标值对应。连续服务、互斥模式、需求只计一次以及禁止连接都是适配层的具体责任。小例枚举原模型和转换模型的完整解，同时核服务次数、容量、代价与达到最优值的路线。相关转弯路由见[P498](<../笔记/10_路由模型与经典搜索/逐篇笔记/P498.md>)、[P504](<../笔记/10_路由模型与经典搜索/逐篇笔记/P504.md>)。

## 转弯代价与连接几何

若连接c已经包含出口到入口的整段转弯长度，再加同一转弯罚金会重复计费。若c仅含基础通行费用，则额外罚金必须明确发生位置、单位和构型。

旧专题中两种小间距公式分别为：

```text
L_B(x) = r[3π − 4 arcsin((2r+x)/(4r))]
L_Z(x) = 2r[π − arctan(x/√(4r²−x²))],   0 ≤ x < 2r
```

两式在x=0分别为7πr/3和2πr，趋近2r时均趋于πr。使用前要核对起终航向、倒车许可和转弯构型。共同的宽间距分支x+(π−2)r并不使整个模型等价。Bochtis与Vougioukas的地头模型见[P323](<../笔记/12_机器人运动与任务执行/逐篇笔记/P323.md>)；Dubins与Reeds–Shepp的运动条件见[P347](<../笔记/12_机器人运动与任务执行/逐篇笔记/P347.md>)、[P362](<../笔记/12_机器人运动与任务执行/逐篇笔记/P362.md>)。

轨迹长度和轨迹位于可行区域内分别验收。边界、障碍、车辆扫掠、曲率和跟踪条件要沿最终轨迹检查；离散碰撞采样同时记录分辨率与误差。

## 现有实验给出的约束

- [36例服务模式实验](../../experiments/results/搜索机制/全库论文应用与两项机制验证/阅读入口.md)：模式DP与精确原图一致；丢弃方向在32例产生错误。
- [144例车具规划](../../data/packages/fleet/files/REPORT.zh.md)：109例联合可行，三个分阶段对照分别完成92、94、95例。路线划分和车具分配需要联合考虑。
- [72例Dubins排序](../../experiments/reports/服务与运动/Dubins固定航向排序.md)：固定连接图可行数65→67；此处的图最优顺序仍是连续运动问题中的限定子问题。

后续农业任务在这个状态基础上加入完整覆盖和执行检查。生成器与推荐器共用同一任务定义和独立检查器。
