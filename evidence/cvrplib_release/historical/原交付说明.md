# CVRPLIB 运行前修复与验收

本包是 URP 的独立补充交付，不是完整仓库，不覆盖历史实验。基于 GitHub 提交 f110f039854f7314e36632ce7d3ee977cd0de0fc；新增代码尚未发布到 main。

## 使用入口

- 环境安装、单次运行、评分和复现命令：src/research/docs/CVRPLIB_READINESS.md。需要 Linux x86_64、Python 3.12；不能直接把本包轮子用于其他 Python 版本或架构。未在用户 Ubuntu 主机实装。
- 协议和准入审查：experiments/protocols/。准入包与正式实验计划分开；本包不含正式 53 例多种子比较结果。
- 本次试跑证据：acceptance/20261014T084727Z/；测试夹具修正后的最终证据：acceptance/20261014T085915Z-test-hardening/。独立审计：audits/cvrplib/。
- 原始 CVRPLIB 输入、参考解及来源记录：data/benchmarks/CVRPLIB/。离线依赖：runtime/cvrplib/。
- 历史恢复证据：evidence/recovery/。其中被中断的旧试跑不计入本次通过数量。

## 已核实与限制

53 例参考解均通过覆盖、容量、车队合同和整数距离复算；原有 100 份文件来源哈希吻合，另补 6 份参考解。53 例对应 51 个坐标需求底本；中大规模全属 X 系列，不能把来源差异当成纯规模效应。

修正测试夹具后，99 项核心回归连续三次通过，随后独立复跑也通过；15 项独立故障检查通过。10 次构造小例及 7 次公共算例试跑均有合法解。它们证明准入能力，不证明算法优越性。末轮复验曾暴露错误分类测试共用过短启动预算的问题，已将错误分类探针与截止时间探针分开，要求确实进入被测阶段，未修改生产求解预算；原失败保留。旧监督器扩展测试另有一次时序敏感失败，原始失败与随后无修改复跑日志均保留；不能声称消除了该偶发风险。

PyVRP 原归档成员和依赖已独立核对。VND 原 ZIP 的独立重下载校验尚缺：交付源码与恢复清单一致，但这不等于已重新验证原归档全部字节。不得把这个来源环节标为完成。

运行器更改不改写历史 253 PASS、历史实验结果或旧协议。正式实验仍须另行冻结计划、算法版本、数据与运行登记表，保留失败与未启动分母。
