# 路径接口与仿真接入

这是基于 URP 提交 418fffe99eccb6487f2497d29d36d0e0913548f6 的增量源码与证据，不是整个 URP 仓库的替代品。

- docs/路径研究与仿真方案.md：研究、通用性、官方资源、成功失败标准及阶段方案。
- src/backend：本次新增或修改的 8 个后端文件，需结合原仓库使用。GET route-scene 只读，不运行求解器或仿真。
- src/robotics：可选路线显示适配和可丢弃接口测试夹具。主仿真应复用官方现成资源，不以夹具替代正式仿真。
- evidence/path_integration：测试、合成合同检查、补丁与文件哈希。

后端71项单测和4种合成合同格式集成通过；适配夹具29项纯Python测试通过。实际 ROS/RViz/Gazebo 尚未运行，前端尚未接入验收；不包含新训练模型或正式算法比较结果。

未来运行前先选择获准的兼容环境和锁定的官方模型/地图。不要将基准任意XY坐标直接作为仿真米制坐标；不要将访问折线作为可避障导航路径。

没有修改冻结求解算法、原始实验记录、原始失败记录或既有外部权限。文件清单保存本次交付哈希；源代码原有版本在Git历史中保留。
