# 离线依赖复现

Linux x86_64、Python 3.12；共14个固定wheel。Drive交付保留展开文件，GitHub复用仓库既有 experiments/results/路线求解/公共路线强基线.zip 的相同成员，不重复存储14份二进制。两端覆盖相同依赖内容，但不是展开路径逐字节同构。

从仓库根目录恢复到标准 runtime/cvrplib/wheels：

    python3 runtime/cvrplib/restore_wheels.py

脚本先核验原ZIP大小及SHA256、每个成员的唯一性/大小/SHA256，再写入；同名同字节文件可复核，遇到不同字节拒绝覆盖。默认归档与逐文件映射见 WHEEL_ARCHIVE_MAP.json。恢复已在新空目录实测，14项与封存wheel逐字节相同，见 RESTORE_VERIFICATION.json。

再创建环境并按哈希安装：

    python3.12 -m venv .venv-cvrplib
    .venv-cvrplib/bin/python -m pip install --no-index --require-hashes --find-links runtime/cvrplib/wheels -r runtime/cvrplib/requirements.lock

原 INSTALL.log 与 RESTORATION_RECEIPT.json 保留先前PREEXEC来源与安装过程；本次新增映射独立证明最终r1原归档提供同一组14个wheel。此处不声称已在用户主机安装。
