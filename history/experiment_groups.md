# 历史实验分组清单

固定版本：50b3b2c2cc7377e1f13dcaeebce09abf5619dbf8。此清单覆盖 experiments/results 下每一个三级目录或归档，以及 data/packages 和 data/research 的规范数据组。文件/归档数不是独立实验数；同一研究的增量、重分析、失败轮和规范化记录可能重复。

本轮通过 GitHub 读取全部报告文本、完整分组目录树和部分原始 JSON/CSV；未解包全部归档，未重跑算法。报告映射按标题精确或前缀匹配，模糊匹配明确标注，不能用本清单替代原报告的统计边界。

共 169 项取用单元，其中 160 个实验目录/归档，另有规范数据组。完整机器可读字段见 [experiment_groups.csv](experiment_groups.csv)。
