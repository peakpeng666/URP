# 编译与维护

## 直接重新编译PDF

已交付的PDF由XeLaTeX编译，不是Word另存为PDF。`main.tex`为入口，`body.tex`为完整正文。

在已安装TeX Live/XeLaTeX及所需字体的环境中：

```bash
cd source
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

输出`source/main.pdf`。运行两遍用于刷新目录及内部引用。依赖包括ctex、fontspec、geometry、amsmath、amssymb、booktabs、longtable、array、calc、xcolor、fvextra、xurl、hyperref、bookmark、fancyhdr、etoolbox、needspace；使用XeLaTeX，不使用pdfLaTeX。

字体名称：DejaVu Serif、DejaVu Sans、DejaVu Sans Mono、Noto Serif CJK SC（含Bold）、Noto Sans CJK SC（含Bold）、Noto Sans Mono CJK SC。包内不附字体。缺字或找不到字体时，先安装对应字体并刷新系统字体缓存，或明确修改main.tex与重建脚本中的字体配置；字体变化可能影响分页。

## 从同一正文重建Word和PDF

`manual_ready.md`是完整内容源；修改后使用：

```bash
python source/build_documents.py
```

重建脚本依赖系统`pandoc`、`xelatex`以及Python的`python-docx`。本次使用Pandoc 3.1.11.1。脚本会生成`typeset.md`、`body.tex`、`main.tex`，更新包根目录的DOCX/PDF并覆盖`logs/latex_build.txt`。不要只改body.tex后再运行脚本，否则改动会被Markdown内容源覆盖。只改排版时同步修改重建脚本的排版规则。

`references.bib`是82条来源的可复用BibLaTeX @online登记，不伪造完整论文作者元数据。本手册采用带核验备注的人工编排参考资源附录；当前编译不调用BibTeX或Biber，不依赖该BIB才能生成PDF。正式论文应从作者/出版社导出对应版本的规范引文后再引用。

`resources.py`可重新生成CSV和JSON；它不是联网爬虫，不会自动重新核验。修改资源后，还需同步手册附录、HTML和BIB，避免来源版本不一致。

## 修改后检查

重新运行教学测试；重新编译并渲染文档；逐页检查公式、表格、长链接、标题与分页。外部链接的存在性与研究结果可重复性是不同验证，不能用排版通过替代实验通过。
