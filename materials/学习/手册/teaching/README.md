# 纠错与验证器教学实验

这里不是EoH实现，不调用语言模型，不执行外部生成的代码，也不是生产沙箱。

## 运行

在独立的Python虚拟环境中安装`requirements.txt`，然后运行：

```bash
python -m pip install -r requirements.txt
python -m pytest -q
python lab.py
```

Ubuntu 22.04可先使用已有的受支持Python创建虚拟环境。此代码以Python 3.10及以上语法编写；本次实际测试仅在Python 3.13.5、NumPy 2.3.5、pytest 9.0.2完成，未声称已在Ubuntu 22.04或Python 3.10实测。`requirements-tested.txt`记录本次观察到的直接依赖版本；其中NumPy版本不适合所有旧Python。不要把本教学环境直接套用于要求Python低于3.13的LLM4AD。

## 文件与检查

`lab.py`：修正后的数值GA、独立TSP计分/验证、n≤9精确TSP、最近邻、三种装箱策略、独立装箱验证以及原指南错误的最小重现。

`test_lab.py`：29项测试。覆盖空适应度错误、有限值检查、GA种子与评价次数、零代/单维边界、微型TSP及重标号/缩放、装箱可行性与非法输入。

`../logs/`：本次实际运行的环境与结果。通过这些测试仅表明这些已写测试通过，不构成一般算法正确性证明；GA数值只用于教学回归，不是研究性能结论。

## 建议先独立完成的修改
