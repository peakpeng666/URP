# 核心文档排版源

[返回工作文档](../README.md)

`build.py` 从两份 DOCX 提取内容，套用对应模板，再编译 PDF。输入与输出路径都相对脚本定位，可从任意工作目录调用。

| 模板 | 内容源 | PDF 输出 |
| --- | --- | --- |
| [实施方案.tex](实施方案.tex) | [实施方案 DOCX](../项目/实施方案_20260908.docx) | [实施方案 PDF](../项目/实施方案_20260908.pdf) |
| [入门指南.tex](入门指南.tex) | [导师指南 DOCX](../学习/LLM自动算法设计入门指南.docx) | [导师指南 PDF](../学习/LLM自动算法设计入门指南.pdf) |

在项目根目录执行：

```powershell
python -B Docs/排版源/build.py --check  # 只检查输入、模板和命令是否存在
python -B Docs/排版源/build.py          # 重建两份 PDF，覆盖上述输出
python -B Docs/排版源/build.py --keep   # 重建并保留中间文件供检查
```

需要 Pandoc、latexmk、XeLaTeX 以及模板使用的字体和宏包。`--check` 不编译，因此不能证明字体、宏包、版面或逐页渲染通过。

默认清理只移除本管线明确生成的中间文件及编译产物，不递归清理其他目录。`media/` 保留实施方案中的插图；README、模板、新增笔记和其他资料不会被清理。每次更改内容后仍需核查最终 PDF。

学习包的手册有独立的 [编译与维护流程](../学习/手册/source/编译说明.md)，不要与此处的导师原指南混用。
